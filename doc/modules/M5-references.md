### T5.2 · Интерактивные стэши

Ключевая особенность, отличающая Cogit от большинства клиентов.

- [x] Клик по стэшу **мгновенно** показывает его файлы в панели Files
- [x] Выбор файла показывает diff — **без** `stash apply`
- [x] Чтение через `gix` (стэш — обычный коммит), не через `git stash show`
- [x] Отображение всех трёх частей стэша: изменения worktree, index, untracked

**DoD:** просмотр содержимого стэша не меняет рабочую директорию — проверяется тестом,
сравнивающим `status` до и после.

### T5.7 · Журнал безопасности и Undo

Реализация [INV-12](../01-architecture.md#inv-12). Самая ценная часть модуля.

- [x] Запись перед деструктивной операцией: описание и что нужно вернуть (`Recovery`).
      Пока покрыты `discard`, `branch -D` и `checkout` (последний — как необратимый)
- [x] Автоматический stash перед операциями, затрагивающими рабочую директорию
- [x] `Undo` кнопкой в тулбаре; шорткат придёт с Command Palette
- [x] Журнал виден пользователю списком — пока только последняя запись в подсказке кнопки
- [x] Честная индикация: операции, которые откатить нельзя, помечены явно

**DoD:** для каждой деструктивной операции есть тест «выполнить → Undo → состояние совпадает
с исходным» (сравнение по OID всех ссылок и по `status`).

Список операций, обязательных к покрытию: `reset --hard`, `discard`, `branch -D`,
`stash drop`, `rebase`, `merge --abort`, `cherry-pick`, `revert`, `checkout` с потерей изменений.

## Известные ловушки

| Ловушка | Последствие | Как избежать |
|---|---|---|
| `stash show` через CLI на каждый клик | Задержка 30 мс на выбор | Читать через `gix` |
| `branch -D` без записи в журнал | Безвозвратная потеря ветки | Журнал до операции |
| Checkout с несохранёнными изменениями | Git откажет или потеряет правки | Проверка `status` и предложение автоstash |
| Reflog без фильтрации достижимых | Секция забита обычными коммитами | Отбирать только недостижимые |
| Зависимость от расширения `git-flow` | Не работает без установки | Реализовать обычными командами |
| Undo, который «почти» восстанавливает | Хуже отсутствия Undo | Тест на точное совпадение состояния |
