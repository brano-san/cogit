# M2 · Макет, многооконность и меню

**Статус:** `TODO` · **Вехи:** A, B · **Зависит от:** M0 · **Блокирует:** M3, M5, M6

Каркас интерфейса, в который остальные модули вставляют содержимое панелей.

Профильные документы: [05-ui-layout.md](../05-ui-layout.md), [06-design-system.md](../06-design-system.md).

## Задачи

### T2.1 · Сетка панелей
- [ ] Компонент сплиттера: ручка 1 px, зона захвата 5 px, смена курсора
- [ ] Вложенная раскладка из [05-ui-layout.md §2](../05-ui-layout.md#2-сетка-главного-окна)
- [ ] Минимальные размеры, запрет схлопывания в ноль
- [ ] Двойной клик по ручке — сброс пропорции
- [ ] Размеры хранятся **в долях**, не в пикселях
- [ ] Сохранение в `tauri-plugin-store`, восстановление при запуске

**DoD:** смена разрешения монитора не ломает раскладку; размеры переживают перезапуск.

### T2.2 · Перспективы
- [ ] `Main`, `Review`, `Reset Perspective`
- [ ] `Shift+F11` — разворот активной панели и возврат
- [ ] Размеры сохраняются **на перспективу**, а не глобально
- [ ] Скрытие панелей через меню `View`

**DoD:** переключение между перспективами сохраняет размеры каждой.

### T2.3 · Тулбар и статус-бар
- [ ] Тулбар 40 px, группы кнопок с разделителями 1 px
- [ ] Неприменимые действия `disabled`, а не скрыты
- [ ] Тултипы с названием и шорткатом
- [ ] Индикатор фоновых операций, кликабельный
- [ ] Статус-бар 24 px со всеми полями из [05-ui-layout.md §3.7](../05-ui-layout.md#37-status-bar-24-px)

**DoD:** кнопки не меняют положение при смене состояния репозитория.

### T2.4 · Нативные меню
- [ ] Строка меню приложения: `Repository`, `Edit`, `View`, `Remote`, `Local`, `Branch`, `Query`, `Tools`, `Window`, `Help`
- [ ] Контекстные меню через `tauri::menu` + `ContextMenu::popup()` (D-01)
- [ ] Пункты меню синхронизированы с шорткатами из [11-keybindings.md](../11-keybindings.md)
- [ ] Динамическое включение/выключение пунктов по состоянию

**DoD:** контекстное меню — нативное меню ОС, а не HTML-элемент.

### T2.5 · Отдельное окно File Compare / 3-Way Merge
- [ ] Создание через `WebviewWindowBuilder`
- [ ] Параметры передаются в URL, не через глобальное состояние
- [ ] Общий `AppState` между окнами
- [ ] Событие `merge-resolved` обратно в главное окно
- [ ] Подтверждение при закрытии с несохранёнными правками

**DoD:** окно переживает перезагрузку webview и восстанавливает своё содержимое из URL.

### T2.6 · Диалог ошибки Git
- [ ] Открывается на `CogitError::GitCommand`
- [ ] Команда, код возврата, блоки `stderr` и `stdout` моноширинным шрифтом
- [ ] Текст выделяется мышью, URL кликабельны
- [ ] Кнопка `Copy Output` через `tauri-plugin-clipboard-manager`
- [ ] **Немодальный** — не блокирует работу с остальным приложением

**DoD:** ручной тест на `git push` в защищённую ветку показывает полный ответ сервера.

### T2.7 · Панель Output
- [ ] Выдвижная нижняя панель, `Ctrl+Shift+7`
- [ ] История всех команд: время, команда, код возврата, длительность
- [ ] Развернуть/свернуть вывод конкретной команды
- [ ] Фильтр по коду возврата (только ошибки)
- [ ] Копирование строки и всего журнала

**DoD:** каждая выполненная Cogit команда Git видна в панели.

### T2.8 · Общие компоненты
- [ ] Виртуализированный список (используется в Graph, Files, References)
- [ ] Дерево с раскрытием (Repositories, References)
- [ ] Поле фильтра с крестиком очистки
- [ ] Пустое состояние панели
- [ ] Скелетон-строки загрузки
- [ ] Тултип

**DoD:** компоненты покрыты тестами логики в `vitest`, поведение единообразно во всех панелях.

### T2.9 · Output Console: не только ошибки

Расширение T2.7. Git сообщает о смешанных окончаниях строк, правах доступа, хуках
и устаревших настройках через `stderr` — **при успешном коде возврата**. Сейчас эти
предупреждения не видит никто.

- [ ] Захватывать `stderr` каждой команды, в том числе успешной ([INV-05](../01-architecture.md#inv-05))
- [ ] Непустой `stderr` при коде 0 — это предупреждение: индикатор в статус-баре, не диалог
- [ ] Панель Output показывает точную команду, полный вывод, код возврата и длительность
- [ ] Подсветка: ошибки красным, `warning:` и `hint:` янтарным
- [ ] Кнопка «Copy log», закрытие по `Esc`
- [ ] Немодальная: читать вывод и смотреть на дерево веток можно одновременно

**DoD:** `git push`, вернувший 0 и напечатавший ссылку на создание PR, оставляет
запись в Output и заметный, но не блокирующий индикатор.


## Приёмка модуля

- [ ] Все токены дизайн-системы применены, ни одного литерального цвета
- [ ] Клавиатурная навигация работает во всех панелях одинаково
- [ ] Фокус виден
- [ ] Проверено при масштабе 100%, 125%, 150%
- [ ] Чек-лист из [06-design-system.md §10](../06-design-system.md#10-чек-лист-перед-мержем-ui-изменений) пройден

## Известные ловушки

| Ловушка | Последствие | Как избежать |
|---|---|---|
| Размеры сплиттеров в пикселях | Раскладка ломается на другом мониторе | Хранить доли |
| HTML-дропдаун вместо нативного меню | Не похоже на приложение ОС, проблемы с фокусом | `tauri::menu` |
| Модальный диалог ошибки | Нельзя посмотреть состояние репо, читая ошибку | Немодальное окно |
| Спиннер по центру панели при загрузке | Содержимое «прыгает» | Скелетон-строки |
| `outline: none` на фокусе | Клавиатурная навигация вслепую | Явная обводка |
