### T6.7 · Жёлоб CodeMirror для построчного стейджинга

Интерфейсная половина T6.3: сама генерация патчей описана там, здесь — как ею управляют.

- [ ] Кастомный `gutter` CodeMirror 6 напротив каждого ханка: `Stage`, `Unstage`, `Discard`
- [ ] Те же действия для выделенного диапазона строк
- [ ] Декорации строк подсвечивают, что именно попадёт в индекс при нажатии

- [ ] `Discard` в жёлобе подтверждается всегда: отменить его нечем, кроме скрытого стэша

**DoD:** стейджинг одной строки из ханка обновляет статус файла и остаётся видимым
в панели Files в пределах 200 мс.

### T6.8 · Commit What You See

Если в списке файлов активен фильтр, `Commit All` коммитит **только видимые** файлы.

- [x] Кнопка меняет подпись на `Commit 4 shown`, когда фильтр активен
- [x] Рядом — счётчик скрытых изменений: `12 more changed files are hidden by the filter`
- [x] Подтверждение показывает полный список того, что будет закоммичено

**DoD:** при активном фильтре скрытые файлы остаются незакоммиченными, и пользователь
видел их число до подтверждения.

**Почему с предупреждением.** Фича удобна, но рискованна: «я нажал Commit All, значит
всё закоммичено» — естественное ожидание. Подпись кнопки и счётчик скрытого
обязательны, иначе это ловушка, а не удобство.

## Известные ловушки

| Ловушка | Последствие | Как избежать |
|---|---|---|
| Патч с нормализованными LF для CRLF-файла | `git apply` перезаписывает файл с неверными EOL | Обратная нормализация перед применением |
| Забытый `\ No newline at end of file` | Патч не применяется или портит последнюю строку | Явная обработка маркера |
| Неверный пересчёт счётчиков `@@` | `git apply` отклоняет патч | Пересчитывать заново, не править исходные |
| Применение патча без логирования | Невозможно разобрать инцидент | Писать патч в лог до применения |
| `Discard` без стэша | Безвозвратная потеря работы | Скрытый стэш для Undo |
| Список из 50 000 untracked-файлов | Зависание UI | Свёртка директорий |
| Amend опубликованного коммита без предупреждения | Расхождение с remote, force-push | Проверка наличия коммита в upstream |
