## Задачи

### T7.1 · Блочный diff (`diff_engine`)
- [ ] Алгоритм Histogram через `imara-diff` 0.2
- [ ] Интернирование строк
- [ ] Нормализация окончаний строк с учётом `.gitattributes` и `core.autocrlf`
- [ ] Определение бинарных файлов, изображений, слишком больших файлов
- [ ] Декодирование не-UTF-8 с флагом `lossy_encoding`
- [ ] Опции: контекст, игнорирование пробелов и пустых строк

**DoD:** чек-лист тестов из [08-diff-engine.md §11](../08-diff-engine.md#11-чек-лист-тестов-diff_engine)
полностью зелёный. Отдельно: файл, различающийся только EOL, даёт специальную плашку,
а не 100% изменений.

### T7.2 · Внутристрочный word-diff
- [ ] `similar` с фичей `inline`
- [ ] Unicode-сегментация границ слов
- [ ] Эвристика отключения при несопоставимых объёмах блоков
- [ ] Байтовые смещения, корректные на многобайтовых символах

**DoD:** тест на строке с кириллицей и эмодзи — смещения указывают на правильные символы
после пересчёта в позиции CodeMirror.

### T7.3 · Ханки и сворачивание
- [ ] Группировка в ханки с объединением близких
- [ ] Заголовки `@@` в формате unified diff
- [ ] Плашки `▲ N lines hidden ▲`
- [ ] Разворот на 20 строк по клику, полностью — по `Ctrl` + клик
- [ ] Заголовок ханка с именем функции через `tree-sitter` (C++ в первую очередь)

**DoD:** структура ханков совпадает с выводом `git diff` на наборе тестовых файлов.

### T7.4 · Параллелизм
- [ ] Diff пачки файлов через `rayon::par_iter` внутри `spawn_blocking`
- [ ] Отмена расчёта при смене выбранного коммита

**DoD:** коммит с 500 файлами обрабатывается быстрее 2 секунд;
быстрое переключение между коммитами не накапливает фоновые задачи.

### T7.5 · Side-by-Side вьюер
- [ ] Оценка `@codemirror/merge` на пригодность (R-10) — **решение принимается здесь**
- [ ] Два `EditorView` с синхронным скроллом
- [ ] Фоновая заливка блоков по дизайн-системе
- [ ] Подсветка изменённых слов поверх фона
- [ ] Соединительные сплайны Безье в полосе между панелями
- [ ] Переключение Side-by-Side / Unified
- [ ] Навигация по изменениям `F6` / `Shift+F6`
- [ ] Поиск внутри diff

**DoD:** синхронный скролл не расходится на файлах с большими вставками;
сплайны совпадают с положением блоков при любом состоянии сворачивания.

### T7.6 · Подсветка синтаксиса
- [ ] Lezer через `@codemirror/lang-*`: C++, Markdown, JS/TS, HTML, CSS
- [ ] Определение языка по расширению и `.gitattributes`
- [ ] Тема подсветки с прозрачным фоном, чтобы не перебивать заливку diff
- [ ] Отключение подсветки на очень больших файлах
- [ ] Никаких токенов из Rust ([INV-01](../01-architecture.md#inv-01))

**DoD:** подсветка не мешает читать блоки diff; файл на 100 000 строк не вешает редактор.

### T7.7 · Сравнение изображений
- [ ] Side-by-Side с масштабированием
- [ ] Swipe-слайдер
- [ ] Onion Skin с регулировкой прозрачности
- [ ] Отображение размеров и веса обеих версий

**DoD:** PNG, JPEG, SVG, WebP открываются; неподдерживаемый формат даёт понятное сообщение.

### T7.8 · 3-Way Merge
- [ ] Чтение stage 1/2/3 из index через `gix`
- [ ] Четыре панели: Theirs, Base, Ours, редактируемый результат
- [ ] Навигация по конфликтам, взятие версии для одного и для всех конфликтов
- [ ] Ручное редактирование результата
- [ ] `Ctrl+S` сохраняет и помечает файл разрешённым
- [ ] Синтаксическое слияние через `tree-sitter` для непересекающихся узлов AST
- [ ] Автоматически разрешённые конфликты помечены и подлежат просмотру

**DoD:** конфликт из фикстуры `conflicted()` разрешается целиком внутри Cogit;
автоматическое разрешение применяется только при непересекающихся узлах AST.

```bash

cargo insta review -p diff_engine
npm run test -- diff
```

- [ ] Все тесты `diff_engine` зелёные
- [ ] Бюджеты производительности из [08-diff-engine.md §9](../08-diff-engine.md#9-производительность) выдержаны

- [ ] Синхроскролл не расходится

## Известные ловушки

| Ловушка | Последствие | Как избежать |
|---|---|---|
| Код по памяти об `imara-diff` 0.1 | Не компилируется или считает неверно | docs.rs для 0.2.0 |
| `similar` без фичи `inline` | Нет API word-diff | Явно указать фичу |
| Diff без нормализации EOL | 100% изменений на каждом файле Windows | [INV-08](../01-architecture.md#inv-08) |
| Смешение байтовых и символьных смещений | Подсветка съезжает на кириллице | Тесты на многобайтовых строках |
| Word-diff на блоке 500↔3 строк | Секунды на расчёт бессмысленного результата | Эвристика отключения |
| Непрозрачный фон темы подсветки | Заливка diff не видна | Прозрачный фон в теме Lezer |
| Автослияние при пересекающихся узлах AST | Молчаливая потеря чужих изменений | Только непересекающиеся узлы, всегда с пометкой |
