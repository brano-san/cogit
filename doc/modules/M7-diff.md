## Задачи

- [x] Интернирование строк

- [x] Декодирование не-UTF-8 с флагом `lossy_encoding`

### T7.2 · Внутристрочный word-diff
- [x] `similar` с фичей `inline`

**DoD:** тест на строке с кириллицей и эмодзи — смещения указывают на правильные символы

### T7.3 · Ханки и сворачивание

**DoD:** структура ханков совпадает с выводом `git diff` на наборе тестовых файлов.

### T7.4 · Параллелизм

### T7.6 · Подсветка синтаксиса
- [x] Lezer напрямую через `@lezer/*`, **без** CodeMirror: Rust, C/C++, JS/TS, Python, JSON, CSS, HTML
- [x] Определение языка по расширению; `.gitattributes` пока не учитывается
- [x] Тема подсветки с прозрачным фоном, чтобы не перебивать заливку diff
- [x] Отключение подсветки на очень больших файлах

**DoD:** подсветка не мешает читать блоки diff; файл на 100 000 строк не вешает редактор.

### T7.7 · Сравнение изображений

### T7.8 · 3-Way Merge
- [x] Чтение stage 1/2/3 из index через `gix`
- [x] Четыре панели: Theirs, Base, Ours, редактируемый результат
- [x] Навигация по конфликтам, взятие версии для одного и для всех конфликтов
- [x] Ручное редактирование результата
- [x] `Ctrl+S` сохраняет и помечает файл разрешённым
- [x] Синтаксическое слияние через `tree-sitter` для непересекающихся узлов AST — C++ и TypeScript; Markdown не делали
- [x] Автоматически разрешённые конфликты помечены и подлежат просмотру

**DoD:** конфликт из фикстуры `conflicted()` разрешается целиком внутри Cogit;
автоматическое разрешение применяется только при непересекающихся узлах AST.

### T7.9 · Детекция перемещения фрагментов

Перенос функции внутри файла сейчас выглядит как удаление в одном месте и добавление
в другом — два блока шума вместо одного факта.

- [x] После блочного диффа искать удалённые и добавленные участки с совпадающим содержимым
- [x] Порог: не менее 3 строк, совпадение после нормализации отступов
- [x] Перемещённые блоки получают отдельный цвет и парный маркер «откуда → куда»
- [x] Соединительная линия в полосе между панелями отличается от обычной пунктиром
- [x] Переключатель в шапке: показывать перемещения или считать их обычными правками

**DoD:** функция, перенесённая из начала файла в конец, показывается как одно перемещение,
а не как удаление плюс добавление.

**Ориентир.** Git решает ту же задачу через `--color-moved`; его эвристики (минимальная
длина блока, игнорирование отступов) стоит взять за отправную точку, а не изобретать свои.

### T7.10 · Переключатель игнорирования пробелов

- [x] Кнопка в шапке панели Diff: `Ignore whitespace`
- [x] Три режима вместо двух: `Off`, `Trailing` (`git diff --ignore-space-at-eol`),
      `All` (`-w`) — поле `ignore_whitespace` в `DiffOptions` уже это допускает
- [x] Состояние запоминается на репозиторий
- [x] При активном режиме в шапке видна пометка, чтобы пользователь не забыл,
      что видит не весь дифф

**DoD:** коммит, меняющий только отступы, в режиме `All` показывается как пустой diff
с явной плашкой «Only whitespace changed».

## Известные ловушки

| Ловушка | Последствие | Как избежать |
|---|---|---|
| Код по памяти об `imara-diff` 0.1 | Не компилируется или считает неверно | docs.rs для 0.2.0 |
| `similar` без фичи `inline` | Нет API word-diff | Явно указать фичу |
| Diff без нормализации EOL | 100% изменений на каждом файле Windows | [INV-08](../01-architecture.md#inv-08) |
| Смешение байтовых и символьных смещений | Подсветка съезжает на кириллице | Тесты на многобайтовых строках |
| Word-diff на блоке 500↔3 строк | Секунды на расчёт бессмысленного результата | Эвристика отключения |
| Непрозрачный фон темы подсветки | Заливка diff не видна | Прозрачный фон в теме Lezer |
| Автослияние при пересекающихся узлах AST | Молчаливая потеря чужих изменений | Только непересекающиеся узлы, всегда с пометкой |
