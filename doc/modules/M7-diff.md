### T7.9 · Детекция перемещения фрагментов

Перенос функции внутри файла сейчас выглядит как удаление в одном месте и добавление
в другом — два блока шума вместо одного факта.

- [ ] После блочного диффа искать удалённые и добавленные участки с совпадающим содержимым
- [ ] Порог: не менее 3 строк, совпадение после нормализации отступов
- [ ] Перемещённые блоки получают отдельный цвет и парный маркер «откуда → куда»
- [ ] Соединительная линия в полосе между панелями отличается от обычной пунктиром
- [ ] Переключатель в шапке: показывать перемещения или считать их обычными правками

**DoD:** функция, перенесённая из начала файла в конец, показывается как одно перемещение,
а не как удаление плюс добавление.

**Ориентир.** Git решает ту же задачу через `--color-moved`; его эвристики (минимальная
длина блока, игнорирование отступов) стоит взять за отправную точку, а не изобретать свои.

### T7.10 · Переключатель игнорирования пробелов

- [ ] Кнопка в шапке панели Diff: `Ignore whitespace`
- [ ] Три режима вместо двух: `Off`, `Trailing` (`git diff --ignore-space-at-eol`),
      `All` (`-w`) — поле `ignore_whitespace` в `DiffOptions` уже это допускает
- [ ] Состояние запоминается на репозиторий
- [ ] При активном режиме в шапке видна пометка, чтобы пользователь не забыл,
      что видит не весь дифф

**DoD:** коммит, меняющий только отступы, в режиме `All` показывается как пустой diff
с явной плашкой «Only whitespace changed».

## Известные ловушки

| Ловушка | Последствие | Как избежать |
|---|---|---|
| Код по памяти об `imara-diff` 0.1 | Не компилируется или считает неверно | docs.rs для 0.2.0 |
| `similar` без фичи `inline` | Нет API word-diff | Явно указать фичу |
| Diff без нормализации EOL | 100% изменений на каждом файле Windows | [INV-08](../01-architecture.md#inv-08) |
| Смешение байтовых и символьных смещений | Подсветка съезжает на кириллице | Тесты на многобайтовых строках |
| Word-diff на блоке 500↔3 строк | Секунды на расчёт бессмысленного результата | Эвристика отключения |
| Непрозрачный фон темы подсветки | Заливка diff не видна | Прозрачный фон в теме Lezer |
| Автослияние при пересекающихся узлах AST | Молчаливая потеря чужих изменений | Только непересекающиеся узлы, всегда с пометкой |
