## Задачи

### T1.1 · Чтение через `gix`
- [x] `RepoManager::open(path)` — обнаружение репозитория через `gix::discover`
- [x] `head()` — текущая ветка, detached-состояние, пустой репозиторий
- [x] `branches()` — локальные и удалённые (upstream и ahead/behind — отдельной задачей)
- [x] `tags()` — lightweight и annotated, с разыменованием
- [x] `status()` — три сравнения: HEAD ↔ index ↔ worktree (счётчики; списки файлов — M6)
- [x] `commit_range(cursor, limit)` — итератор истории в топологическом порядке
- [x] `commit_details(oid)` — автор, коммиттер, даты, сообщение, родители
- [x] `submodules()` — разбор `.gitmodules` с рекурсией
- [x] `repo_state()` — состояния из [03-git-semantics.md §4](../03-git-semantics.md#4-состояния-репозитория)

**DoD:** каждый метод покрыт тестом на соответствующей фикстуре M9;
для **каждого** состояния репозитория есть тест, доказывающий отсутствие паники ([INV-07](../01-architecture.md#inv-07)).

### T1.2 · Исполнитель команд Git
- [x] Единая точка запуска (`std::process::Command` внутри `spawn_blocking`, не `tokio::process`)
- [x] Требования из [03-git-semantics.md §3](../03-git-semantics.md#3-запуск-команд-git):
      явный `current_dir`, захват обоих потоков, `GIT_TERMINAL_PROMPT=0`, `LC_ALL=C`,
      `GIT_OPTIONAL_LOCKS=0` для чтения, аргументы массивом, таймаут
- [x] Тип `GitCommandError` со всеми полями ([INV-05](../01-architecture.md#inv-05))
- [x] Журнал всех запущенных команд для панели Output
- [x] Ограничение 1 МБ на поток с явной пометкой об обрезке

**DoD:** тест на заведомо падающей команде проверяет, что `stdout` и `stderr`
попали в ошибку **целиком** и не были подменены.

## Известные ловушки

| Ловушка | Последствие | Как избежать |
|---|---|---|
| Хранение `gix::Repository` в глобальном состоянии | Устаревшие данные после мутаций через CLI | `ThreadSafeRepository`, открывать на время операции |
| Вызов `gix` напрямую в async-задаче | Блокировка воркера Tokio | `spawn_blocking` |
| Забытый `WorkerGuard` логгера | Молча теряются последние строки лога | Хранить в состоянии приложения |
| Парсинг вывода `git` без `LC_ALL=C` | Ломается на локализованном Git | Задавать переменную всегда |
| Конкатенация путей в строку команды | Ломается на пробелах и Unicode | Только массив аргументов |
| Реакция на собственные изменения ФС | Бесконечный цикл обновлений | Пауза наблюдения на время мутации |
