### T3.3 · Мультивыбор и групповые операции

## Известные ловушки

| Ловушка | Последствие | Как избежать |
|---|---|---|
| Рекурсия по сабмодулям без ограничения глубины | Зависание на циклических ссылках | Ограничение глубины и учёт посещённых путей |
| Открытие сабмодуля как отдельного репо без учёта `.git`-файла | Не находится репозиторий | `gix::discover` умеет читать `.git` как файл |
| Блокирующий `Fetch All` последовательно | Пять репозиториев по 10 секунд = минута | Параллельно, с ограничением одновременных задач |
| Хранение абсолютных путей без нормализации | Дубликаты при разном регистре на Windows | Канонизация пути перед сравнением |
