# Cogit — Горячие клавиши

> Единый реестр. Добавление шортката без записи сюда запрещено — иначе конфликты
> обнаруживаются пользователем, а не разработчиком.

## 1. Области действия

Шорткат действует в **области** (scope). Один и тот же аккорд может значить разное
в разных областях — это нормально и нужно, если области не пересекаются визуально.

| Область | Когда активна |
|---|---|
| `global` | Всегда в главном окне |
| `graph` | Фокус в панели Graph & History |
| `files` | Фокус в панели Files |
| `refs` | Фокус в панели References |
| `repos` | Фокус в панели Repositories |
| `diff` | Фокус в панели Diff |
| `merge-window` | Окно 3-Way Merge |
| `investigate-window` | Окно Investigate (§9a) |
| `modal` | Открыт диалог или палитра |

Разрешение конфликта: `modal` > конкретная панель > `global`. Модальные слои лежат стеком: клавишу
получает только верхний, а пока открыт хоть один, панели, глобальные клавиши и команды меню
молчат (кроме `Alt+X` — Exit); аккорд меню окно у страницы всё равно забирает ([R-451](12-risks.md)).

## 2. Глобальные

| Аккорд | Действие |
|---|---|
| `Ctrl+Shift+P` | Find Command — палитра команд |
| `Ctrl+P` | Find Object — поиск коммита, ветки, тега, файла |
| `Ctrl+O` | Open Repository |
| `Ctrl+W` | Close Repository |
| `Ctrl+Shift+7` | Панель Output (журнал команд Git) |
| `Ctrl+,` | Настройки Cogit — `Edit ▸ Preferences…` (до #42 — `Repository ▸ Settings…`, теперь это настройки репозитория, без аккорда). Там же раздел Toolbar: пункта `Edit ▸ Configure Toolbar…` и команды `configure-toolbar` больше нет (R-371), аккорда у них не было |
| `F5` | Refresh — перечитать состояние репозитория. Пункта в меню нет (#43), клавишу по-прежнему перехватывает окно, иначе WebView2 перезагрузил бы страницу; есть в палитре команд |
| `Alt+X` | Exit — выход с подтверждением (R-151, R-168); `Alt+F4` ведёт туда же |
| `Shift+F11` | Развернуть активную панель / вернуть раскладку |
| `F6` / `Shift+F6` | Фокус на следующую / предыдущую видимую панель. Из панели Diff с открытым diff — сначала по изменениям (§7), за последним — дальше по панелям |
| `Ctrl+1` … `Ctrl+7` | Показать/скрыть панель (`View`): Repositories, References, Graph, Files, Commit Message, Diff, Worktrees |
| `Esc` | Закрыть диалог, снять фильтр, отменить выделение |
| `Enter` в диалоге | Кнопка с фокусом; вне кнопки — действие по умолчанию (в Exit с операциями — Cancel; R-167, R-169) |
| `Tab` / `Shift+Tab` в диалоге | По кругу внутри диалога |

Аккорды, у которых есть пункт нативного меню, обрабатывает меню, а не webview:
иначе одно нажатие срабатывало бы дважды. Так же окно перехватывает аккорды команд без
пункта в меню (`OFF_THE_BAR` в `menu.rs`: `F5`, `Ctrl+Shift+Enter`, `Ctrl+K`, `Ctrl+Shift+Y`). Клавишу `Enter` меню пишет
`Enter`, а не `Return` — `Return` muda не читает, и пункт остаётся без аккорда. Масштаба
интерфейса (`Ctrl+=` / `Ctrl+-` / `Ctrl+0`) и справки (`F1`) нет: WebView2-масштаб Tauri
выключен, своего нет ([R-453](12-risks.md)).

## 4. Индекс и коммит

| Аккорд | Область | Действие |
|---|---|---|
| `Ctrl+T` | `global` | Stage — `Local ▸ Stage`: отмеченные в Files файлы, а без отметок — все изменения, как кнопка тулбара |
| `Ctrl+Shift+T` | `global` | Unstage — `Local ▸ Unstage`, так же |
| `Ctrl+Z` | `files` | **Discard** — откатить изменения отмеченных файлов (см. предупреждение ниже); ловит webview, не меню |
| `Ctrl+Enter` | `global` | Commit — `Local ▸ Commit…`: показывает панель Commit Message, ставит в поле курсор и коммитит, если коммит готов (R-452) |
| `Ctrl+Shift+Enter` | `global` | Commit --amend — то же с галочкой Amend; команда без пункта в меню (`OFF_THE_BAR`, `commit-amend`) |
| `Ctrl+K` | `global` | Фокус на поле сообщения коммита; показывает панель, если она скрыта (`OFF_THE_BAR`, `commit-message`) |
| `Space` | `files` | Отметить строку или снять отметку (множественный выбор, F-101); ставит в индекс `Ctrl+T` |
| `Ctrl+A` | `files` | Выделить все файлы |

> **Предупреждение о `Ctrl+Z`.**
> В исходной спецификации `Ctrl+Z` назначен на Discard, как в SmartGit. Но во всём остальном
> софте `Ctrl+Z` означает «отменить последнее действие», а здесь он **уничтожает** несохранённую
> работу. Мышечная память пользователя работает против него.
>
> Принятые меры:
> 1. `Ctrl+Z` действует только в области `files`, никогда глобально: в Diff и в полях ввода это
>    обычная отмена, окно этот аккорд не перехватывает.
> 2. Discard **всегда** спрашивает подтверждение, если затронуто более одного файла
>    или более 20 строк.
> 3. Отброшенные изменения перед удалением складываются в скрытый стэш и доступны
>    через `Undo` в течение сессии ([INV-12](01-architecture.md#inv-12)).
> 4. В поле ввода сообщения коммита `Ctrl+Z` — обычная отмена ввода.

## 5. Ветки и история

| Аккорд | Действие |
|---|---|
| `F7` | Создать ветку — `Branch ▸ New Branch…` |
| `Shift+F7` | Создать тег — `Branch ▸ Create Tag` |
| `Ctrl+Shift+R` | Interactive Rebase от выбранного коммита — `Local ▸ Rebase Commits After This One…` |

Checkout, Merge, Rebase, Cherry-Pick, Revert и Undo аккордов не имеют: это пункты
контекстных меню графа и Branches, кнопки тулбара и команды палитры. Merge и Rebase тулбара
идут без вопроса — одиночный аккорд на них слишком лёгок; `Ctrl+Shift+Z` в поле ввода — это
повтор ввода, окно его не забирает ([R-453](12-risks.md)).

`Branch ▸ Bisect` (`Start…`, `Mark HEAD as Good`, `Mark HEAD as Bad`, `Skip HEAD`, `Reset`) аккордов
по умолчанию тоже не имеет: пункты есть в редакторе Keyboard, сочетание назначается там (F-565).

## 6. Стэши

| Аккорд | Действие |
|---|---|
| `Ctrl+S` | Stash All (см. примечание) |
| `Ctrl+Alt+S` | Stash Selection — только выделенные файлы |

> **Примечание о `Ctrl+S`.**
> В главном окне это Stash All везде, в том числе в поле сообщения коммита и в панели слияния:
> окно забирает аккорд пункта меню раньше страницы (R-70), и результат слияния там пишет кнопка
> Save resolution. **Save** аккорд означает только в отдельном окне слияния (F-216): меню у него
> нет, и клавиша доходит до страницы.

## 7. Diff и навигация по изменениям

| Аккорд | Область | Действие |
|---|---|---|
| `F6` | `diff`, `merge-window` | Следующее изменение / конфликт |
| `Shift+F6` | `diff`, `merge-window` | Предыдущее изменение |
| `Ctrl+Shift+D` | `global` | Переключить Side-by-Side / Unified |
| `Ctrl+F` | `diff` | Поиск в diff |
| `←` / `→`, `Home` | разделитель колонок Side-by-Side в фокусе | Сдвинуть на 2 % / поровну (R-535) |

Клавиши области `diff` в главном окне действуют, только пока фокус в панели Diff (щелчок в ней или
`F6` до неё): `F6` из Graph переводил фокус и одновременно листал diff, `Ctrl+F` из поля сообщения
коммита уводил фокус в поиск diff. `F6` за последним изменением и `Shift+F6` перед первым
отдаются обходу панелей (§2), иначе с клавиатуры из Diff не уйти. Так же `Ctrl+Alt+Shift+L` и
`Esc`, закрывающий поиск. Слияние конфликта в панели Diff так же ходит по конфликтам `F6` и
`Shift+F6`, пока фокус в панели, и отдаёт их обходу за последним и перед первым; прочие клавиши
слияния (§9) — только в его окне: `Ctrl+S` и `Ctrl+1…3` главного окна принадлежат меню
(`panelConflictStep` в `lib/merge-view.ts`). `Ctrl+Shift+D` — из любой панели. В отдельных окнах (сравнение,
Investigate) клавиши diff действуют всегда. Правило — `diffKey` в `lib/diff-keys.ts`.

Своей строки поиска у WebView2 нет ни в одном окне: `Ctrl+F`, `Ctrl+G`, `Ctrl+Shift+G`, `F3`,
`Shift+F3`, на которые никто на странице не ответил (`Ctrl+F` вне панели Diff, над бинарным
файлом), гасит `suppressBrowserFind` (`lib/browser-find.ts`, R-536).

Stage и Unstage выделенных строк — кнопки над diff, свёрнутый блок разворачивает щелчок: аккордов
у них нет: на раскладках с AltGr сочетания `Ctrl+Alt` — это ввод символов, а не команды.

## 9. Окно 3-Way Merge

| Аккорд | Действие |
|---|---|
| `Ctrl+S` | Сохранить результат и пометить конфликт разрешённым |
| `F6` / `Shift+F6` | Следующий / предыдущий конфликт |
| `Ctrl+1` | Взять Theirs для текущего конфликта (без текущего — для первого) и перейти к следующему |
| `Ctrl+2` | Взять обе стороны (`both`): отдельной версии Base у выбора нет |
| `Ctrl+3` | Взять Ours |
| `Ctrl+Shift+1/2/3` | То же для **всех** конфликтов |

Цифры — по месту клавиши, с любой раскладкой; пока результат правится руками, выбор сторон
клавишами не действует. Только в отдельном окне: в панели слияния главного окна `Ctrl+1…7`
и `Ctrl+S` — аккорды меню.
| `Ctrl+W` | Закрыть окно (с подтверждением при несохранённых правках) |

### 9.1. Отдельные окна: сравнение, слияние, Blame

| Аккорд | Окно | Действие |
|---|---|---|
| `Esc` | все | Закрыть окно; открытая панель поиска внутри окна забирает `Esc` первой. Окно слияния с выбранной стороной или правкой результата сначала спрашивает — так же `Ctrl+W`, Cancel и крестик (04 §7) |
| `Ctrl+W` | все | Закрыть окно; в Blame — ещё и пункт `File ▸ Close` его меню |
| `↑` / `↓`, `PageUp` / `PageDown`, `Home` / `End` | Blame | Сменить текущую строку — под ней `History of current line` |
| `F5` | Blame | Перечитать blame и версии файла (`View ▸ Refresh`), а не перезагрузить страницу |

### 9.2. Окно Investigate

Нативное меню окна ([R-283](12-risks.md)): аккорды ниже — акселераторы его пунктов, они
показаны справа в меню и срабатывают через меню, а не через webview. Пока фокус в странице,
WebView2 забирает клавиши себе, поэтому окно, как и главное, перехватывает ровно аккорды
своего меню раньше страницы (`child_window::accelerator_table`, `AcceleratorKeyPressed`);
так же — `F5` и `Ctrl+W` окна Blame.

| Аккорд | Действие |
|---|---|
| `Esc`, `Ctrl+W` | Закрыть окно (`Esc` сначала закрывает список Back, справку или поиск в diff) |
| `Alt+←` / `Alt+→` | Back / Forward по шагам исследования |
| `Alt+↑` / `Alt+↓` | Более новая / более старая версия файла в Navigation |
| `Ctrl+1` … `Ctrl+5` | Перспектива Log, Diff, Blame, Blame+Origins, Origins |
| `Ctrl+D` | Go Deeper — к версии до коммита-источника |
| `F6` / `Shift+F6` | Следующее / предыдущее изменение этой версии в Blame |
| `F5` | Перечитать лог и blame |
| `Ctrl+Shift+C` | Копировать ID коммита выбранной строки |
| `F1` | Как работает Investigate |
| `↑` / `↓` | Строка в Blame, коммит в Navigation, кандидат в Origin Candidates |
| `Enter` в Origin Candidates | Go Deeper в выбранного кандидата |

Пересечения только с другими окнами: `Ctrl+1…5` и `F1` — отдельное окно со своим меню,
как у 3-Way Merge; в перспективе Diff `F6` / `Shift+F6` передаются самому diff.

## 10. Навигация в списках

Одна функция на все панели-списки — `lib/list-keys.ts` (`listKey`, поиск по вводу); граф
ходит тем же `nextRow`. Расхождения между панелями — только те, что в таблице ([R-454](12-risks.md)).

| Аккорд | Действие |
|---|---|
| `↑` / `↓` | Переместить выделение — Graph, Branches, Files, Worktrees. В Repositories — только фокус: выбор строки открывает репозиторий, это делает `Enter` |
| `Shift+↑` / `Shift+↓` | Расширить отметку файлов — Files; в остальных панелях как `↑` / `↓` |
| `Home` / `End` | К началу / концу списка |
| `PageUp` / `PageDown` | Страница |
| `←` / `→` | Свернуть / развернуть узел — Branches (`←` на листе — к его заголовку), submodule в Repositories |
| `Enter` | Действие по умолчанию: в Branches — то же, что двойной щелчок по узлу (диалог Checkout у ветки и тега, у папки — свернуть или раскрыть; R-560), открыть репозиторий, submodule или worktree; в Files — показать файл в Diff, как щелчок |
| `Ctrl+A` | Отметить все показанные файлы — Files; граф выделения не имеет |
| Ввод символов | Перейти к строке, имя которой начинается с набранного (пауза 0,8 с начинает заново, повтор одной буквы идёт по совпадениям) — Branches, Files, Repositories, Worktrees; в графе вместо этого фильтр |

Меню кнопок тулбара (каретка split-кнопки и «…») — `lib/menu-keys.ts`: открытое с клавиатуры
(`Enter`/`Space` на кнопке) ставит фокус на первый пункт; `↑` / `↓` — по доступным пунктам по
кругу, `Home` / `End` — к первому / последнему, `Enter` — пункт, `Esc` — закрыть и вернуть фокус
кнопке, `Tab` — закрыть и идти дальше. Те же клавиши — у меню лупы в фильтре графа (и у меню
настроек графа рядом с ним); там `Delete` на сохранённом шаблоне забывает его (F-563).

## 11. Реестр конфликтов

Проверено на пересечения в пределах каждой области.

| Аккорд | Потенциальный конфликт | Разрешение |
|---|---|---|
| `Ctrl+S` | Stash All ↔ Save | Разные окна: главное (Stash All, и в полях ввода) против окна слияния (Save) |
| `Ctrl+Z` | Discard ↔ ожидаемый Undo | Только область `files`, всегда подтверждение; в полях и в Diff — отмена ввода. Undo операций — кнопка тулбара и `Local ▸ Undo Last Operation`, без аккорда |
| `Ctrl+A` | Выделить всё ↔ выделить текст | В полях ввода побеждает ввод |
| `Ctrl+W` | Close Repository ↔ Close Window | В отдельных окнах — закрытие окна |
| `Ctrl+P` | Find Object ↔ Print | Печати в приложении нет |
| `Ctrl+F` | Поиск в diff ↔ Fetch | Fetch перенесён на `Ctrl+Shift+F` |
| `Ctrl+Shift+O` | Push ↔ Open | Open на `Ctrl+O` |
| `F5` | Refresh ↔ перезагрузка страницы WebView2 | Аккорд перехватывает окно, хотя пункта Refresh в меню нет (#43) |
| Любой аккорд меню | Запись сочетания в Preferences ▸ Keyboard ↔ сама команда | Пока кнопка ждёт «Press keys…», окно не перехватывает клавиши (`capture_keys`); уход фокуса с кнопки, `Esc` и закрытие Preferences возвращают перехват |

Preferences ▸ Keyboard записывает только то, что окно перехватывает: `claimable` в
`lib/keymap.ts` — то же правило, что `accelerators::parse`, обе стороны проверяют
`accelerator-cases.json`. `Ctrl` или `Alt` с буквой, цифрой, `, . - =`, `Enter` или стрелкой;
F-клавиша — и без модификаторов; всё по месту клавиши, с любой раскладкой. `AltGr`, `Win`,
`Space`, `Tab`, `Delete`, `Ctrl+/` и одиночная буква — «cannot be used here»;
`Ctrl+A/C/V/X/Z/Shift+Z/Y/F` оставлены полям и панелям, `Alt+F4` — системе ([R-516](12-risks.md)).

## 12. Правила при добавлении шортката

1. Проверить по этому файлу, что аккорд свободен в целевой области.
2. Не переопределять системные аккорды ОС (`Alt+F4`, `Win+*`, `Ctrl+Alt+Del`).
3. Деструктивное действие не вешается на одиночную клавишу без модификатора.
4. Шорткат действия тулбара показывается в его тултипе, и тултип не обещает аккорда, которого
   нет. Merge и Rebase тулбара идут без вопроса, поэтому аккорда у них нет (R-453).
5. Каждый шорткат обязан находиться через палитру команд `Ctrl+Shift+P`.
   Палитра и тултипы тулбара не пишут аккорд строкой: его берёт `shortcutOf` (`lib/keymap.ts`)
   по id команды из действующей раскладки — с переназначениями Preferences ▸ Keyboard, `Cmd`
   на macOS. У действия тулбара — поле `command` (id команды меню); `keys` — только для
   аккорда страницы без пункта меню (`Ctrl+Z` у Discard).
6. Добавить строку в соответствующую таблицу этого файла **в том же коммите**.
