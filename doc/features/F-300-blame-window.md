# F-300 · Окно Blame

Blame файла открывается отдельным окном с заголовком `<файл> - Blame of <путь>@<хеш>`: сверху
`View Commit` и `Highlight: Changes Since`, в середине строки с хешем, автором и датой у каждого
блока, снизу `History of current line`. Проверить: Blame из панели Diff → окно; выбрать в
`Highlight: Changes Since` старый коммит — подсветились строки новее; стрелками сменить строку —
история под ней обновилась; двойной клик по строке истории показывает ту версию файла;
`Esc`, `Ctrl+W`, `File ▸ Close` и крестик закрывают окно, главное окно работает дальше.
