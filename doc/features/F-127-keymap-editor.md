# Настройка горячих клавиш

Категория Keyboard позволяет переназначить клавишу любой команды меню, показывает конфликты и сразу перестраивает меню.

Назначение применяется и сохраняется сразу, как любое поле Preferences: `OK`, `Esc` и крестик его не теряют, `Cancel` возвращает раскладку, какой она была при открытии, а `Restore Defaults` на странице Keyboard снимает все переназначения.
