# Investigate: история выделенного фрагмента

Для диапазона строк файла можно получить хронологический список правок — новые сверху, по
каждой свой diff, автор и дата; список не прерывается на переименовании файла, а коммиты,
не трогавшие этот фрагмент, в нём не появляются.

Заменено окном Investigate: [F-380](F-380-investigate-window.md), [F-381](F-381-origin-candidates.md).
