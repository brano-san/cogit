# Просмотр стэша без применения

Клик по стэшу показывает его файлы тремя разделами — рабочее дерево, индекс и неотслеживаемые, — не трогая рабочую директорию.

Стэш, удалённый пока он открыт (Drop, Pop, `git stash drop` в терминале), уходит из Files и Diff сам: панели возвращаются к рабочему дереву, тулбар снова предлагает Stage и Discard.
