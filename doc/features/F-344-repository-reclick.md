# F-344 · Повторный клик по репозиторию ничего не перезагружает

Клик по уже активному репозиторию в Repositories ничего не перечитывает, а клик по
репозиторию, чей submodule или worktree сейчас в панелях, возвращает к нему сразу, без
«Opening repository…» и без повторной загрузки дерева submodules. Проверить: открыть
submodule двойным кликом, затем кликнуть его репозиторий — дерево submodules остаётся
раскрытым как было, панели не мигают.
