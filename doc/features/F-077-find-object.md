# F-077 · Поиск объекта по Ctrl+P

- [ ] Ctrl+P открывает поиск, который по одной строке находит ветку, тег, коммит (по хешу или сообщению) и файл, показывая их отдельными группами.
- [ ] Слово из букв a–f и цифр (`added`, `cafe`, `feed`) ищется и как начало хеша, и в сообщениях
      коммитов; поиск начинается, когда набор замирает, а не на каждую букву.
- [ ] Выбор ветки (своей или удалённой), тега или коммита выделяет его коммит и прокручивает к нему граф; рабочая копия не переключается. Файл открывается в Diff выбранного коммита, а на Working
      Tree — в Diff рабочей копии (staged-версия, если файл изменён только в индексе).
