# F-077 · Поиск объекта по Ctrl+P

- [ ] Ctrl+P открывает поиск, который по одной строке находит ветку, тег, коммит (по хешу или сообщению) и файл, показывая их отдельными группами.
- [ ] Выбор ветки (своей или удалённой), тега или коммита выделяет его коммит и прокручивает к нему граф; рабочая копия не переключается. Файл открывается в Diff выбранного коммита.
