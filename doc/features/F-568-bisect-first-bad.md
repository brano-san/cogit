# F-568 · Bisect: первый плохой коммит и Leave Bisect

- [ ] Когда git называет первый плохой коммит, он выбирается в графе и показывается в списке, а баннер пишет `First bad commit found` с его id и темой и кнопками `Show Commit` и `Reset`; Reset после конца поиска ничего не спрашивает.
- [ ] Если поиск закончил шаг, сделанный в Cogit, открывается `Bisect Finished`, как в SmartGit: id, автор и дата, сообщение; `Copy ID`, `Continue Bisect` (закрыть, остаться в bisect) и `Leave Bisect` (`git bisect reset`). Шаг из терминала диалога не открывает — хватает баннера и выбора в графе.
- [ ] Остались только пропущенные коммиты — git отвечает ошибкой (код 2) со списком, окно ошибки показывает его вывод, а баннер — `Bisect cannot narrow it down` с кандидатами и Reset.
- [ ] Открытие репозитория, уже закончившего поиск, выбор в графе не трогает: для этого есть `Show Commit`.
- [ ] Проверить в сборке: последний `Mark as Bad` — диалог, в графе выбран первый плохой; `Continue Bisect` — диалог закрыт, баннер на месте; `Leave Bisect` — HEAD снова на исходной ветке.
