# F-090 · Визуальный interactive rebase

- [ ] Диалог «Rebase…» (пункт `Rebase Interactive From` контекстного меню коммита) показывает коммиты после выбранного списком, где каждому можно задать pick, reword, edit, squash, fixup или drop и переставить перетаскиванием, и запускает rebase без единого текстового редактора.
- [ ] Окно — общий диалог: `Enter` (вне кнопок) запускает rebase, когда план годен; `Tab` ходит
      по кругу внутри. Переставить коммит или сменить действие → щелчок мимо окна ничего не
      закрывает, `Esc` и ✕ спрашивают «Discard Changes».
- [ ] Красная плашка о force-push — только когда на remote уже есть коммит из плана, а не
      база: два локальных коммита поверх `origin/main`, rebase после вершины `origin/main` —
      плашки нет.
