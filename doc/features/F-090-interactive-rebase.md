# F-090 · Визуальный interactive rebase

- [ ] Диалог «Rebase…» (пункт `Rebase Interactive From` контекстного меню коммита) показывает коммиты после выбранного списком, где каждому можно задать pick, reword, edit, squash, fixup или drop и переставить перетаскиванием, и запускает rebase без единого текстового редактора.
