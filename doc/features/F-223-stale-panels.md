Когда на диске что-то меняется, заголовки затронутых панелей помечаются точкой, которая гаснет, как только панель перечиталась.

- [ ] Точка не мигает (R-591): перечитывание короче 600 мс её не зажигает, зажёгшаяся гаснет
      через 1,5 с тишины. Проверить: открыть репозиторий с submodule, склонированным на месте
      (`.git` — папка внутри рабочего дерева), и запустить в нём `git status` раз в секунду —
      у Files и Repositories точки нет; правка файла, пока идёт долгое перечитывание, — ровная
      точка, пока оно не кончится.
