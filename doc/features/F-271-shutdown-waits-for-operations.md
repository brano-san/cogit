# F-271 · Выключение Windows ждёт операций

Выход из сеанса Windows во время push показывает экран Windows «Cogit — 1 operation is
still running» и предупреждение в самом Cogit; без операций сеанс завершается без
вопросов. Проверить: начать длинный push и выйти из сеанса — Windows ждёт; нажать «Отмена»
на экране Windows — в Cogit открыт диалог с push.
