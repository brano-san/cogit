# Строка графа: правые колонки на месте

Автор, аватар, время и хеш закреплены у правого края строки и не уходят за него. Когда
места не хватает, сначала сжимаются метки веток (усечение посередине, хвост имени
остаётся), затем тема (многоточие), а если полос графа всё равно больше, чем помещается,
область графа обрезается у края с затуханием — полосы не сжимаются (R-331). Видимые колонки
и их порядок, формат времени, плотность строк и полосатость — параметры списка для
настроек графа.
