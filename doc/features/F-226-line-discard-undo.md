# Построчный Discard обратим

Отмена выделенных строк в жёлобе diff запоминает применённый патч, и Undo возвращает ровно эти строки, не трогая остальной файл.

Подтверждение так и говорит: «Undo can put them back». После Discard строк перечитываются
список файлов и журнал безопасности — Undo в тулбаре и меню сразу подписан этой записью.
