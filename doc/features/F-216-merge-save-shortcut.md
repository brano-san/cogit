# F-216 · Ctrl+S сохраняет разрешение

- [ ] В окне слияния (кнопка ⧉ над панелью слияния) `Ctrl+S` записывает результат и помечает
      файл разрешённым; пока остался хоть один неразрешённый конфликт, кнопка Save resolution
      и сочетание не срабатывают. В панели слияния главного окна `Ctrl+S` — это Stash All из
      меню (R-70), результат там записывает кнопка Save resolution.
