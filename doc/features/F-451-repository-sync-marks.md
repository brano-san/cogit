# F-451 · Изменения, push и pull в строке Repositories

У каждой строки Repositories — открытой, неактивной или закрытой — слева от имени слот точки
«есть изменения» (жёлтая точка; у чистой строки слот пуст, но имена всех строк начинаются с
одной вертикали), а на углах иконки — стрелка вверх (есть что пушить) и вниз (есть что
забрать); числа — в подсказке. Строки, которых нет на экране, читаются в фоне по одной, и
никогда — пока активный репозиторий занят. В Preferences → Commands → General → Pull —
«Fetch in the background» с интервалом (по умолчанию выключено): fetch без запросов учётных
данных, ошибка — `?` вместо стрелки pull и запись в лог, без уведомления. Проверить: изменить
файл в закрытом репозитории — точка появляется; сделать коммит в клоне remote и включить фон
раз в 5 минут — у строки появляется стрелка вниз; remote с недоступным URL — `?`.
