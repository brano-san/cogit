# F-451 · Изменения, push и pull в строке Repositories

У каждой строки Repositories — открытой, неактивной или закрытой — слева от имени слот точки
«есть изменения» (жёлтая точка; у чистой строки слот пуст, но имена всех строк начинаются с
одной вертикали), а на углах иконки — стрелка вверх (есть что пушить) и вниз (есть что
забрать); числа — в подсказке. Строки, которых нет на экране, читаются в фоне по одной, и
никогда — пока активный репозиторий занят. В Preferences → Commands → General → Pull —
«Check the remotes in the background» с интервалом (по умолчанию выключено): сервер
спрашивается `ls-remote` без fetch и без записи, без запросов учётных данных; стрелка вниз
появляется и тогда, когда сервер ушёл вперёд после последнего fetch; ошибка — `?` вместо
стрелки pull и запись в лог, без уведомления. Наблюдатель есть только у репозитория, который
показывают панели (R-351): строки, которых панели не показывают, открытые и закрытые,
перечитываются, когда окно Cogit снова получает фокус (не чаще раза в минуту; фокус внутри
минуты — чтение в её конце); ветку строка берёт из того же чтения — у открытой и у закрытой.
Точка считает изменения так же, как строка на экране, — вместе с неотслеживаемыми файлами и
submodules, поэтому не появляется и не пропадает при выборе строки (R-540). Те же метки — у
узлов submodules (F-545).
Проверить: изменить файл в закрытом или неактивном репозитории в другой программе и
вернуться в Cogit — точка появляется; репозиторий, где есть только новый неотслеживаемый файл
или сдвинутый submodule, — точка есть и у выбранной строки, и после перехода на другую; `git switch other` там же — у строки `other`; сделать коммит в клоне remote и включить фон
раз в 5 минут — у строки появляется стрелка вниз; remote с недоступным URL — `?`.
