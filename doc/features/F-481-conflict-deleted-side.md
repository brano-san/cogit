# Конфликт «изменён / удалён» разрешается удалением файла

Если файл удалили на одной стороне и изменили на другой, он открывается тремя сторонами с
«Absent on this side» вместо слияния по строкам. Кнопка стороны, которая файл удалила,
называется «Take ours (delete)» или «Take theirs (delete)» и удаляет файл (`git rm`); другая
сторона оставляет файл с её содержимым.
