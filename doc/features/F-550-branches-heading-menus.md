# F-550 · Меню заголовков, папок и HEAD в Branches

У каждого узла Branches есть `Toggle`: у ветки, тега, stash-а, потерянного коммита — его
флажок; у HEAD, заголовка группы и папки — тройной флажок всего внутри (R-555). `Local
Branches` — `Add Branch…` (на выбранном коммите или HEAD), `Tags` — `Add Tag…`. Проверить:
правый щелчок по `Tags` ▸ `Toggle` отмечает все теги, второй раз снимает; по папке `feature/` —
только её ветки; `Add Branch…` у `Local Branches` создаёт ветку на выбранном в графе коммите.
