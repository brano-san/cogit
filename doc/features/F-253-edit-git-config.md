# F-253 · Edit Git Config

`Repository ▸ Edit Git Config ▸ Repository…` и `User…` открывают конфиг во встроенном
редакторе с подсветкой; Save проверяет текст через git и не пишет файл, который git
не принял. Проверить: дописать строку `[broken`, нажать Save — видна ошибка с номером
строки, а файл на диске прежний.

Обе области — один компонент `ConfigEditor`. Путь над редактором всегда виден целиком по
высоте: редактор занимает оставшееся место, а не столько, сколько просят его строки;
длинный путь усекается в середине (`fitPath`), целиком — в подсказке (#22, R-610).
Проверить: открыть конфиг репозитория на 60+ строк в окне шириной ~900 px — путь виден
полностью; при сужении окна пропадают папки из середины пути, а не его низ.
