# Поиск внутри diff

`Ctrl+F` открывает строку поиска над diff: все совпадения подсвечены, текущее выделено
ярче, счётчик показывает «третье из семнадцати», `Enter` и `Shift+Enter` переходят к
следующему и предыдущему, `Escape` закрывает. Поиск идёт по обеим колонкам side-by-side
и по всем показанным строкам, а не только по видимой части; свёрнутые полосы `N lines
hidden` в него не входят, о чём говорит подсказка поля `Find in shown lines` (R-471). Чтобы
искать по всему файлу, раскрыть полосы: `Ctrl` + клик по полосе открывает все.
