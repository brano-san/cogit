# Поиск внутри diff

`Ctrl+F` открывает строку поиска над diff: все совпадения подсвечены, текущее выделено
ярче, счётчик показывает «третье из семнадцати», `Enter` и `Shift+Enter` переходят к
следующему и предыдущему, `Escape` закрывает. Поиск идёт по обеим колонкам side-by-side
и по всему файлу, а не только по видимой части.
