# F-515 · Код в Diff и слиянии прокручивается вбок

- [ ] Строка в 150 символов с правкой последнего слова, Side by side при панели ~900 px: под
      строками полоса прокрутки; полоса, Shift+колесо или свайп тачпада двигают код обеих
      колонок вместе, номера строк и знаки стоят; правка в конце строки видна.
- [ ] То же в Unified. Файл с короткими строками — полосы нет.
- [ ] `Ctrl+F` по слову в конце длинной строки — вид сдвигается к совпадению; `Enter` к
      совпадению в начале строки — вид возвращается влево.
- [ ] Конфликт, различающийся в конце длинной строки: полоса под четырьмя панелями слияния
      двигает все колонки; отступы строк видны; кнопки theirs / ours / both — у правого края
      Result.
