# F-362 · Контекстное меню файла рабочего дерева

Правый клик по файлу в Files на Working Tree: `Open File`, `Reveal in Explorer`,
`Show Changes`, `Log`, `Blame`, `Investigate`, —, `Commit…`, `Stash Selection…`, —, `Stage`,
`Unstage`, `Index Editor…`, `Move or Rename…`, —, `Resolve ▸ Take Theirs / Take Ours`, —,
`Ignore`, `Discard…`, `Remove…`, `Delete…`, —, `Copy Name` / `Path` / `Relative Path`, и в
списке Unstaged — `Toggle 'Assume Unchanged'` / `'Skip Worktree'`. Проверить: на файле в
конфликте `Resolve ▸ Take Ours` оставляет нашу версию и снимает конфликт.
