# Центрирование графа на ссылке

Клик по имени ветки, тега или стэша в панели References прокручивает граф так, что её вершина оказывается в середине окна.

Вершина, которой нет в нарисованной истории (по умолчанию отмечен только HEAD), сначала отмечается в Branches — так же, как Reveal Commit, — и граф перестраивается с ней; ветка из истории HEAD не отмечается. Вершину, которую граф всё равно не покажет (фильтр по пути), граф не ждёт: позже он к ней не прыгнет.
