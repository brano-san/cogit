# F-586 · Welcome: что делать, если ни один репозиторий не открыт

По образцу «Welcome to SmartGit»: модальное окно с тремя вариантами и списком недавних репозиториев.

- [ ] **Когда показывается.** При запуске, если после восстановления прошлой сессии ни один
      репозиторий не открыт (сессия пуста или все пути недоступны), и включено
      `Preferences ▸ General ▸ Starting ▸ Show the Welcome dialog if no repository was opened`
      (`startupShowWelcome`, по умолчанию включено). Решение принимается только после того, как
      `Closed → Opening → Open | Failed` успокоилось и настройки прочитаны (`shouldShowAtStartup`),
      поэтому окно не мигает перед восстанавливаемым репозиторием; запуск его не ждёт — это один
      `$state`. `Repository ▸ Welcome…` и палитра («Welcome…») открывают его в любой момент;
      сочетания клавиш нет.
- [ ] **Содержимое.** «What do you want to do?» и строка «Open or create a local repository, clone
      a remote one, or open a previously used one.». Три варианта (radiogroup): 1 `Add an existing
      local or create a new repository`, 2 `Clone existing repository`, 3 `Reopen previously used
      repository` со списком под ним. Флажок `Show this dialog if no repository was opened`
      (то же значение, что и в Preferences, пишется сразу), кнопки `Close` и `OK` (основная,
      правее). Подписи и флажок не обрезаются — переносятся по словам; при ширине окна 480 px
      ничего не вылезает. Цвета — только токены: фон `bg.elevated`, выбранная строка
      `bg.selected` + `selected.bar`, акцент `accent`.
- [ ] **Выбор по умолчанию.** Вариант 3 и первая строка списка, если список не пуст; иначе вариант 1
      (`defaultSelection`).
- [ ] **Пустой список.** «No repository has been opened yet.» — обычная подсказка варианта 3: сразу под
      его заголовком, тот же отступ и интервал, что у подсказок вариантов 1 и 2, `fg.muted`; места под
      список нет, диалог компактный. Radio и заголовок варианта 3 — `fg.disabled`, выбрать его нельзя
      (клик не действует, стрелки пропускают: `isOptionDisabled`, `moveSelection`, `selectOption`);
      выбран вариант 1.
- [ ] **Список.** Тот же список недавних, что ведёт приложение (`session.recent`, `cogit.session.v1`):
      новые сверху, порядок — по последнему открытию, повторы (в том числе `D:\a` и `d:/A/`) —
      одной строкой (`mruRows`). Строка: имя (`fg.primary`) и полный путь (`fg.muted`), в том числе
      `\wsl.localhost\…` и UNC целиком, с переносом, а не обрезкой; одинаковые имена различаются
      путём. Виден минимум 6 строк, дальше прокрутка внутри списка.
- [ ] **Недоступные пути.** Строки показываются сразу; для каждой асинхронно спрашивается
      `folder_kind` (не больше 4 одновременно, 4 с на путь). Папки нет или это файл — строка
      `fg.disabled` с пометкой «(not found)»; папка есть, но не репозиторий — «(not a repository)»;
      нет ответа за 4 с (мёртвая сеть, WSL) — строка остаётся обычной, а `OK` и двойной щелчок её
      открывают как раньше. Закрытие окна отменяет проверки, поздние ответы отбрасываются.
      Для недоступной строки `OK` неактивна.
- [ ] **Удаление из списка.** `Del` на строке или контекстный пункт `Remove from List` (общее
      контекстное меню). Это не разрушительное действие — папка на диске остаётся, подтверждения
      нет. Убираются все написания пути, выбор остаётся на соседней строке.
- [ ] **Клавиши.** `↑`/`↓` идут по вариантам и дальше по строкам списка (`moveSelection`); выбор
      строки выбирает вариант 3; двойной щелчок или `Enter` на строке открывает репозиторий сразу;
      `Esc`, ✕ и `Close` закрывают окно, главное окно остаётся пустым; `Tab` — флажок и кнопки,
      фокус не выходит из окна. Начальный фокус — на выбранном варианте или строке.
- [ ] **OK по вариантам.** 1: папка из системного выбора; репозиторий (в том числе подпапка
      рабочего дерева, как у Open) открывается; обычная папка — вопрос «Run git init there and
      open it?» в общем окне, после согласия `git init` через `git_engine` и открытие; нет
      папки или это файл — уведомление. Отмена выбора или вопроса возвращает в Welcome.
      2: открывается мастер Clone (F-575) поверх Welcome; `Cancel` возвращает в Welcome, `Finish`
      закрывает его и запускает клон в футере. 3: выбранная строка открывается как через Open.
- [ ] Команды IPC: `folder_kind`, `init_repository` (04-ipc-contract).
