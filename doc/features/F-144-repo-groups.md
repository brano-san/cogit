# Группы репозиториев

Репозитории раскладываются по именованным группам перетаскиванием, группы сворачиваются, а удаление группы возвращает её репозитории в общий список, а не прячет их.

Пока в фильтре списка есть текст, группы с совпадениями раскрыты, а группы без них не
показываются; после очистки фильтра группы снова свёрнуты и раскрыты как до него (R-485).
