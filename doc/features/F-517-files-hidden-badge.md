# F-517 · Значок скрытых файлов в Files

- [ ] Выключить Untracked и набрать в фильтре Files часть имени — слева появляется
      `✕ N files hidden`; щелчок очищает фильтр и включает только Untracked. Unchanged и Ignored
      (в коммите — Unchanged) остаются выключенными: всё дерево и игнорируемые файлы не читаются.
