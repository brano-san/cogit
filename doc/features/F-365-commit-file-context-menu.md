# F-365 · Контекстное меню файла в коммите из истории

Правый клик по файлу выбранного коммита: `Show Changes`, `Compare with Working Tree`,
`Open File` (копия версии только для чтения), `Reveal in Explorer` (выключен, если файла больше
нет), —, `Save As…`, `Log`, `Blame` (на этом коммите), `Investigate`, —, `Cherry-Pick` /
`Revert` изменений этого файла, —, `Copy Path` / `Relative Path` / `Name`. Проверить:
`Revert` на файле старого коммита возвращает в рабочее дерево и индекс его прежнее
содержимое, остальные файлы коммита не меняются.
