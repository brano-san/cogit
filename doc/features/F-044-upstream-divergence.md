# F-044 · Расхождение с upstream

- [ ] Рядом с локальной веткой видно ↑N ↓M относительно её upstream, а `=` означает совпадение.
- [ ] Ветка, чей upstream удалён на сервере (после Fetch с prune его remote-tracking ветки нет), подписана `origin: gone`, как `[origin/x: gone]` у git, а её worktree не считается запушенным.
