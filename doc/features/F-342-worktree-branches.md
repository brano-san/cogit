# F-342 · Ветка, взятая в worktree, помечена в Branches

У локальной ветки, которую держит другой worktree, в Branches стоит значок worktree с
путём в подсказке и его состояние: `clean`, `changes` или `missing`. Проверить: добавить
worktree на ветку, изменить в нём файл — у ветки `changes`; удалить папку — `missing`.
