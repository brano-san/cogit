# F-342 · Ветка, взятая в worktree, помечена в Branches

У локальной ветки, которую держит другой worktree, в Branches стоит компактная метка
`(● worktree)` с путём и состоянием в подсказке. Точка жёлтая (`--indicator-changes`) —
в worktree есть изменения; зелёная (`--indicator-synced`) — чисто и ветка не впереди своего
upstream; серая — чисто, но есть незапушенные коммиты или upstream нет; у отсутствующей
папки метка красная. У remote-tracking ветки метки нет. Проверить: добавить worktree на
ветку, изменить в нём файл — точка жёлтая; закоммитить — серая; запушить — зелёная;
удалить папку — метка красная.
