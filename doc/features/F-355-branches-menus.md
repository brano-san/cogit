# F-355 · Меню ветки, тега и stash-а в Branches

Правый клик по ветке, тегу или stash-у в Branches — списки из #33–#35. Проверить: `Reveal
Commit` ставит галочку и выделяет коммит в графе; `Compare with Selected Commit` выделяет оба
коммита, а в Files — только различающиеся файлы; `Toggle` переключает галочку (есть у каждого узла, F-550); `Copy Message`
у лёгкого тега неактивен.
