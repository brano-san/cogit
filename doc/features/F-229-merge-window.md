# Слияние в отдельном окне

Конфликтный файл открывается кнопкой ⧉ в собственном окне на четыре панели; после сохранения окно закрывается само и сообщает главному событием `merge-resolved`.

Если сохранить не удалось (занят `index.lock`, файл открыт другой программой), окно остаётся: над редактором — полоса с полным выводом git, выбранные стороны и ручные правки на месте, `Save` можно нажать снова.
