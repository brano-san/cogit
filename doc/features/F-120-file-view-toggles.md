# F-120 · Переключатели вида файлов

- [ ] Над списком Files шесть переключателей состояний — Unchanged, Untracked, Ignored,
      Modified, Skipped (skip-worktree и assume-unchanged, R-420) и Missing/Removed; рядом —
      раздельные Working Tree и Index и выбор между каталогами и плоским списком. В узкой
      панели переключатели состояний уходят в меню Customize View, там же колонка Renamed
      Path (источники переименований).
