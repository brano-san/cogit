# F-442 · Ветка коммита по клику

- [ ] С `Branch Coloring` (Preferences ▸ Graph & History ▸ Coloring или меню настроек графа, R-574) клик по коммиту выделяет его ветку — линию первых родителей от точки ответвления до вершины или merge — поверх остальных линий и толще главной; клик по линии в выбранной строке выделяет ветку этой линии.
