# F-256 · Branches открываются свёрнутыми

Репозиторий, открытый впервые, показывает в Branches только свёрнутые заголовки; что
пользователь раскрыл, раскрыто и при следующем открытии. Проверить: открыть новый
репозиторий, раскрыть Local, закрыть и открыть снова — Local раскрыт, остальное свёрнуто.
