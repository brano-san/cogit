# F-083 · Секреты не попадают в журнал

- [ ] Ни в панели Output, ни в лог-файле, ни в диалоге ошибок не видно токена: заголовок авторизации и пароль внутри URL показаны как `<redacted>`.
- [ ] Значение переменной с `token`/`password`/`secret` в имени скрыто только в строке дампа окружения или конфига (`NAME=…`, `export NAME=…`, `remote: NAME=…`); заголовок — только в начале строки или после `remote:`, `>`, `Send header:`, `extraheader=`. Строка, где такое слово лишь упомянуто (ссылка на merge request `…/api-token-service/…?…=feature`, `assertion failed: token.len() == 32`), выводится как есть.
