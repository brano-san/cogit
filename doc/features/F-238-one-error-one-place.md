# F-238 · Одна ошибка показывается в одном месте

- [ ] Открыть папку, которая не является репозиторием: текст ошибки виден во всплывашке справа снизу и нигде больше.
- [ ] Всплывашка сама не исчезает; у неё есть `Copy` и крестик, а длинный текст прокручивается внутри неё.
- [ ] Статус `Error` в футере гаснет ровно в тот момент, когда закрыта последняя всплывашка.
- [ ] Несколько ошибок подряд дают одну всплывашку со счётчиком «ещё N», а не стопку окон.
