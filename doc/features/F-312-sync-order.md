# F-312 · Порядок Sync: Pull, then Push или Push, then Pull

Меню кнопки Sync предлагает `Push, then Pull` и `Pull, then Push`; выбранный пункт
выполняется и становится действием основной кнопки, по умолчанию — `Pull, then Push`.
Проверить: навести на Sync — «Pull, then push»; выбрать в меню `Push, then Pull` —
выполнены push и pull, после перезапуска подсказка «Push, then pull».
