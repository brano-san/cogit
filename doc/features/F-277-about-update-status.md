# F-277 · Статус обновлений в About

Строка `Updates` показывает итог последней проверки за этот запуск: `Up to date`, `x.y.z
available` со ссылкой на релиз или `Not checked` со ссылкой `Check now`, которая запускает
Help ▸ Check for Updates. Проверить: открыть About до проверки — `Not checked`; нажать
`Check now` и открыть снова — строка сменилась.
