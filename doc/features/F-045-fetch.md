# F-045 · Fetch с прогрессом

- [ ] `Remote ▸ Fetch` (`Ctrl+Shift+F`), `Remote ▸ Fetch All` и пункты Fetch в меню кнопки
      Pull забирают изменения с remote, показывая строки Git в футере по мере их появления.
      Кнопка Sync тулбара — не Fetch: она делает Pull, затем Push (порядок выбирается в её
      меню; R-224).
- [ ] После Fetch выбранный коммит и открытый Diff остаются, граф и ссылки перечитываются;
      Fetch All перечитывает панели, только если забирал и репозиторий на экране. Проверить:
      выделить коммит, открыть файл, `Ctrl+Shift+F` — выделение и Diff на месте.
