# F-041 · Создание стэша

- [ ] Кнопка Stash в тулбаре убирает все изменения вместе с неотслеживаемыми файлами, спросив сообщение.
- [ ] `git init`, создать файл: Stash и его меню неактивны («Nothing is committed yet»). На чистом
      дереве `Ctrl+S`, палитра и `Local ▸ Stash All` неактивны, как кнопка («The working tree is
      clean»).
