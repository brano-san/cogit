# F-532 · Диалог с набранным текстом не закрывается молча

- [ ] Repository ▸ Edit Git Config: дописать строку → щёлкнуть мимо окна — окно на месте.
      `Esc` или ✕ — вопрос «Discard Changes»: Cancel возвращает к тексту, Discard закрывает.
      Без правок `Esc` и щелчок мимо закрывают сразу. Так же Index Editor, Edit Message,
      Interactive Rebase (переставленный план), Split Off, изменённый хук в Manage Hooks,
      сообщение тега в Add Tag и имя в Stash All и Stash Selection.
- [ ] С набранным текстом в Edit Git Config закрыть окно Cogit — вопрос «Unsaved Work» называет
      «Edit Git Config — User» и виден поверх редактора.
