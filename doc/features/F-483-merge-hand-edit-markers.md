# Ручная правка слияния с маркерами конфликта

«Edit result by hand» в четырёхпанельном слиянии открывает текст, где у нерешённых
конфликтов обе стороны стоят между маркерами `<<<<<<< ours` / `||||||| base` / `=======`
/ `>>>>>>> theirs`. «Save resolution» недоступна, пока в тексте остаётся хоть один маркер.
Результат записывается с окончаниями строк нашей стороны и без перевода в конце, если его
не было.
