# F-025 · Amend и no-verify

- [ ] Галочки Amend и No verify меняют последний коммит и пропускают хуки, обе выключены по умолчанию.
- [ ] В репозитории без коммитов Amend выключен (подсказка «Nothing to amend: this branch has no commits yet»), кнопка без staged-файлов неактивна, Local ▸ Commit with Amend ничего не делает.
