# F-009 · Файлы коммита

- [ ] Панель Files показывает изменённые коммитом файлы с бейджами A/M/D/R/C, переименование выводится одной строкой со старым путём.
- [ ] Число в заголовке Files — строки того списка, что показан: файлы stash, сравнения, коммита (с Unchanged, если включён) или рабочего дерева.
