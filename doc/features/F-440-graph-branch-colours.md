# F-440 · Отмеченные ветки — своими цветами

- [ ] Ветка, отмеченная галочкой в Branches, рисуется в графе своим цветом от вершины по первым родителям до главной линии или до уже подсвеченной ветки; цвет зависит только от имени ветки (у `origin/x` тот же, что у `x`), не меняется между запусками и различим во всех четырёх темах; неотмеченные линии серые, главная — яркая.
