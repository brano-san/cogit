# F-507 · Аккорды стейджинга и инструментов

- [ ] `Ctrl+T` / `Ctrl+Shift+T` (`Local ▸ Stage` / `Unstage`) ставят в индекс и снимают
      отмеченные в Files файлы, без отметок — все изменения; `Ctrl+Z` при фокусе в Files
      спрашивает и отбрасывает изменения отмеченных файлов, а в поле сообщения коммита остаётся
      отменой ввода. `Ctrl+Shift+L` — Blame файла из Diff, `Ctrl+Shift+Y` — копировать SHA
      выбранного коммита, `Ctrl+Alt+Shift+F` — Fetch All, `F7` — новая ветка, `Shift+F7` — тег,
      `Ctrl+Shift+R` — редактор rebase от выбранного коммита (R-453).
