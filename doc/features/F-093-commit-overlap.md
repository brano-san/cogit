# F-093 · Колонка Commit Overlap

- [ ] View → Commit Overlap Column показывает для каждого видимого коммита, насколько он трогает те же файлы, что и выбранный: `—`, `slight`, `heavy` или `same files`, с тултипом по пересекающимся путям.
- [ ] На строке Working Tree (выбранного коммита нет) колонка пуста, без пересечений и метки `base` прежнего коммита.
