# F-574 · Кнопки Files — в заголовках, видны всегда

- [ ] Заголовки `Unstaged` и `Staged` в Files показывают свои кнопки (`Stage all`,
      `Discard all`…, `Unstage all`) без наведения; у строк файлов кнопок нет, и имя файла
      не закрывается ничем (R-593). В узкой панели усекается подпись заголовка, а не кнопки.
