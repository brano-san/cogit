# F-322 · Remote ▸ Subtree

Подменю `Add…`, `Merge…`, `Split…`, `Reset…`, `Push…` поверх `git subtree`; диалоги
подставляют папки, найденные в истории по `git-subtree-dir:`, и имена remotes. Проверить:
`Add…` с URL другого репозитория, папкой `lib` и веткой `main` — в графе merge-коммит, в
рабочей копии папка `lib/` с файлами того репозитория.
