# F-250 · Окно About отвечает на «какая у вас сборка»

Help ▸ About Cogit показывает иконку, версию, коммит, дату сборки, ОС, рендерер, версии
Rust, Tauri, Svelte, git и gitoxide, ссылку на лицензию и кнопку Copy Diagnostics
(раскладка — F-272). Проверить: нажать Copy Diagnostics и вставить — в буфере всё, что на
экране, плюс то, что окно не показывает (F-275).
