# F-287 · Кнопка Commit видна при любой высоте панели

Строка `Subject N`, `Amend`, `No verify` и `Commit N` прижата к низу панели Commit Message:
при уменьшении высоты сжимается поле сообщения, а сплиттер не даёт сделать панель ниже
заголовка, двух строк поля и строки управления. Проверить: тянуть сплиттер между Files и
Commit Message вниз до упора.
