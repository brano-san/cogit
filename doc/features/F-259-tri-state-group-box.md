# F-259 · Общий чекбокс группы в Branches

Чекбокс группы всегда показывает состояние детей: ✓ — отмечены все, `−` — часть, пусто —
ни одного; клик по пустому или `−` отмечает всех, по ✓ — снимает всех; сворачивание группы
отметки не трогает. Проверить: отметить один тег, кликнуть по «Tags» — отмечены все теги,
свернуть группу — чекбокс остаётся ✓.
