# F-340 · Папки веток и тегов в Branches

На каждом уровне Branches сначала папки со значком папки, затем ветки; теги `release/…`
лежат в папке `release`, папка с единственной подпапкой показана одним узлом
`testing/network`, разделитель тегов берётся из `cogit.tagGroupSeparator` (по умолчанию `/`).
Проверить: в репозитории с ветками `testing/network/a`, `testing/network/b`, `alpha` и
тегами `release/1.0`, `release/1.1` раскрыть Local Branches и Tags.
