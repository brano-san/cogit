# F-241 · Основная ветка идёт слева, сплошной линией

- [ ] Самую левую колонку графа сверху донизу занимает HEAD и цепочка его первых родителей, ответвления уходят только вправо.
- [ ] Когда HEAD стоит на feature-ветке, колонка 0 — её линия, а не `master`; `master`, затем `main` берут колонку, только если HEAD не отмечен в Branches, не показан фильтром или его нет (R-161; решение R-115 «имена первыми» отменено).
- [ ] Линейная история — одна вертикальная линия слева.
- [ ] Линия входит в точку коммита по центру, а не мимо; точки и линии видны без вглядывания.
