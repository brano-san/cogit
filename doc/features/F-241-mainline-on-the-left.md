# F-241 · Основная ветка идёт слева, сплошной линией

- [ ] В репозитории с `master` основная линия занимает самую левую колонку графа сверху донизу, ответвления уходят только вправо.
- [ ] Это верно и когда HEAD стоит на feature-ветке, и когда самый свежий коммит не в основной ветке.
- [ ] Линейная история — одна вертикальная линия слева.
- [ ] Линия входит в точку коммита по центру, а не мимо; точки и линии видны без вглядывания.
