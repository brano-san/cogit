# F-249 · Контекстное меню файла

Правый клик по строке в панели Files открывает меню: Stage, Unstage, Discard, Ignore,
Delete, Blame, History of this file, Show in Explorer, Copy the path — с теми же
аккордами, что на клавиатуре. Проверить: правый клик по изменённому файлу — Stage
доступен, Unstage нет; по файлу коммита — предлагаются только чтение и копирование.
