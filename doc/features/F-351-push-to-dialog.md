# F-351 · Диалог Push To

`Push → Push To…` в тулбаре и `Push To…` в меню ветки или тега открывают диалог
`Push '<ветка>' to remote '<remote>'`: выбор remote (если их несколько), `Tracked or matching
branch` или `Custom Ref` с полем, у ветки — флажок `Set upstream` (включён, если ветка ещё ничего
не отслеживает, R-550). Проверить: Custom Ref `review/x` создаёт на remote ветку
`review/x`; подписи не обрезаны при узком окне.
