# Панель diff переживает стейджинг

После Stage, Unstage или Discard показанный файл пересчитывается на месте, а не исчезает:
место в файле и выделение сохраняются. Панель очищается только когда показывать уже
нечего — правок не осталось или файла больше нет.

Выделение хранится номерами строк, а Stage блока сдвигает индекс под удалениями ниже него.
Поэтому после пересчёта остаются выделенными только строки, которые в новом diff — та же
строка под тем же номером и напротив того же места другой стороны; остальные снимаются, а
не угадываются. Бэкенд, со своей стороны, сверяет выделение с файлами как они есть и
отказывает выделению из устаревшего diff, вместо того чтобы наложить его на другие строки.
