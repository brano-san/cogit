# F-560 · Фильтр графа: где искать текст

- [ ] Поле фильтра в шапке Graph & History с placeholder `Filter`. Пока в поле есть текст, под шапкой показана строка переключателей `Author`, `Committer`, `Message`, `Refs`, `ID`, `Name`, `Content`, `Notes`; по умолчанию включены все, кроме `Name` и `Content` (R-625: они разбирают дерево каждого коммита и отмечены `*`: наведение или фокус на `*` — «May slow the search down considerably on large repositories.»; в Preferences те же `*`). Сохранённый ранее список полей остаётся как был. Коммит показывается, если текст (регистр не важен) нашёлся хотя бы в одном включённом поле: имя или e-mail автора, коммиттера, всё сообщение с телом, имя ветки или тега на коммите, начало хеша, имена изменённых файлов (с `/` в тексте — пути целиком, как в SmartGit), строки, которые коммит добавил или убрал, текст Git Notes коммита (любой `refs/notes/*`). Name и Content считают пачками на всех ядрах, порядок строк прежний (R-625); переключатель сразу перефильтровывает граф; выбор сохраняется в настройках и переживает перезапуск (R-573).
- [ ] Проверить в сборке: у `Name` и `Content` есть `*` с подсказкой (мышью и Tab), у `Notes` нет; включить `Name` на большой истории — результат появляется за секунды, не десятки секунд; ввести имя коллеги-коммиттера — с `Committer` находится, без него нет; ввести имя файла и включить `Name` — находятся коммиты, менявшие его; строку кода с `Content` — коммиты, добавившие или убравшие её; перезапустить — переключатели те же; стереть текст — строка переключателей пропала.

Справочно: SmartGit фильтрует граф по имени файла и изменённому содержимому (changelog SmartGit 20.2–22.1: «filtering for File Name», «filter for modified content»; https://www.smartgit.dev/changelogs/changelog-22.1.txt), имя файла — по имени, путь целиком — если в шаблоне есть `/` (changelog 21.1).
