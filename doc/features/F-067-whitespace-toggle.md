# F-067 · Игнорирование пробелов

- [ ] Кнопка в шапке Diff переключает Off → Trailing → All, а если изменились только пробелы, вместо пустого diff видна плашка с объяснением.
- [ ] Preferences ▸ Diff View ▸ Whitespace = Ignore all whitespace, в файле изменить только отступы: кнопка режима есть в шапке и у такого файла, плашка называет её; щелчок показывает diff.
