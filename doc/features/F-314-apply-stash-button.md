# F-314 · Кнопка Apply Stash

Кнопка `Apply Stash` рядом со `Stash` применяет последний stash (`stash@{0}`) и оставляет
его в списке; без stash-ей она неактивна, а конфликт при применении приходит в окно
уведомлений с выводом Git. Проверить: сделать stash, нажать `Apply Stash` — изменения
вернулись, stash остался в Branches; в репозитории без stash-ей кнопка серая с подсказкой
«There are no stashes».
