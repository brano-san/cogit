# F-096 · Уровень логирования из настроек

- [ ] Выбранный в настройках уровень применяется к крейтам Cogit при следующем запуске, не трогая многословность `gix` и `notify`, а лог по-прежнему не растёт больше 10 МБ плюс два архива.
- [ ] Без сохранённого уровня лог пишется на `info` — том, что показывает Preferences; смена
      другой настройки (например, темы) уровень лога не меняет.
