# F-096 · Уровень логирования из настроек

- [ ] Уровень из Preferences ▸ Tools & Integrations ▸ CLI & Terminal ▸ `Log level` применяется
      к крейтам Cogit при следующем запуске, не трогая многословность `gix` и `notify`. Размер
      лога от уровня не зависит: файл на каждый запуск, после 10 МБ — продолжение, в папке не
      больше 10 файлов ([F-260](F-260-log-per-run.md), INV-04).
