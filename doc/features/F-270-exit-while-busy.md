# F-270 · Выход во время операций: подождать или остановить

Во время push выход показывает предупреждение «1 operation is still running» со строкой
`Push · <репозиторий> · NN%`, без «Don't show again», фокус на Cancel, и Enter его
отменяет; `Exit When Done` выходит, когда push закончится, `Exit Anyway` выходит сразу и
останавливает git. Проверить: начать push, нажать `Alt+X` — пояснения про последнее окно
нет; дождаться конца push при открытом диалоге — он становится обычным вопросом.
