# Fetch All

Обновляет все открытые репозитории, а если в Repositories отмечены строки (`Ctrl`- или
`Shift`-клик), — только отмеченные открытые; обычный клик по строке ничего не отмечает.
Общий счётчик в футере; ошибка в одном не останавливает остальные. Репозитории забираются по
четыре сразу: недоступный remote держит только свой. Тест — `fetch-all.test.ts`.
