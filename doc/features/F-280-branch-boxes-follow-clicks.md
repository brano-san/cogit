# F-280 · Чекбоксы Branches отвечают на каждый клик

Любую ветку, тег, стэш или потерянный коммит можно отметить и снять кликом по чекбоксу, а
общий чекбокс группы идёт по кругу пусто → ✓ → пусто, из `−` — в ✓. Проверить: снять
«Local Branches», отметить одну ветку (группа `−`), кликнуть по группе (✓), ещё раз (пусто),
отметить ветку и снять её.
