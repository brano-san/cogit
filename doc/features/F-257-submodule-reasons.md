# F-257 · Подмодуль, который не открылся, говорит почему

Открытие любого подмодуля из дерева работает и после открытия другого; а если открыть
нельзя, сообщение называет причину — нет каталога, не инициализирован (с предложением
Initialize) или `.git`-файл указывает в путь другой ОС. Проверить: открыть подмодуль,
затем вложенный подмодуль другого родителя — открывается.
