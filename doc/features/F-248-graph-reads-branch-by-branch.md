# F-248 · Граф читается веткой, а не по датам

**Заменено [F-262](F-262-graph-like-smartgit.md):** порядок по дате даёт граф уже (R-162).

Коммиты одной ветки идут в графе подряд: линия ведёт вниз без переходов на соседние
дорожки, даже если по времени ветки перемежались. Проверить: открыть репозиторий, где
две ветки развивались параллельно, — каждая линия должна быть сплошной, а слияние
рисуется кольцом, сквозь которое проходит дорожка.
