# F-508 · Клавиатура в списках

- [ ] В Branches после щелчка по ветке `↓` / `↑`, `PageUp` / `PageDown`, `Home` / `End` выбирают
      соседний узел и центрируют на нём граф, `←` / `→` сворачивают и разворачивают, `Enter`
      выписывает локальную ветку, набор «ma» ставит на первый узел, начинающийся с «ma». В Files
      стрелки ведут выделение (файл открывается в Diff), `Shift+↓` расширяет отметку, `Ctrl+A`
      отмечает всё. В Worktrees стрелки выбирают, в Repositories двигают фокус, `Enter`
      открывает (R-454).
