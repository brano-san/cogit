# F-283 · Изменённый подмодуль в Files показывает два коммита, а не внутреннюю ошибку

Клик по подмодулю со статусом `M` открывает в Diff «Was» и «Now» — записанный и
выбранный коммиты; подмодуль, в котором нет записанного коммита, помечен `not fetched`, а
предупреждение `Submodule commit is not available locally` предлагает `Fetch in submodule`.
Проверить: сдвинуть подмодуль на другой коммит и выбрать его в Files.

Удалённый подмодуль (`git rm lib`, в индексе или коммитом) показывает «was a submodule; this
removes it» и «Was», без «Now» и без Initialize; подмодуль старого коммита, которого нет в
индексе, Initialize тоже не предлагает. Проверить: `git rm lib`, кликнуть `lib` в Staged, затем
закоммитить и кликнуть его в коммите.
