# F-246 · Дерево репозиториев переживает выбор submodule

- [ ] Клик по узлу submodule делает его активным: граф, файлы, ветки и diff показывают его — а дерево остаётся прежним, с родителем, соседями и раскрытыми узлами на местах.
- [ ] Выбранный узел помечен выделением; возврат к родителю — клик по родителю, дерево снова не перестраивается.
- [ ] Двойной клик делает то же и раскрывает узел.
- [ ] Плашка Detached HEAD у submodule не пугает: она сообщает, на каком коммите он стоит, и не предлагает создать ветку.
- [ ] Каретка есть только у репозитория, у которого действительно есть submodules, и она их сворачивает.
