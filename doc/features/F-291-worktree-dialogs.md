# F-291 · Добавление и удаление ворктри

`Repository ▸ Add Worktree…` открывает диалог: папка, новая ветка с базовым коммитом или
существующая (занятую другим ворктри выбрать нельзя — сказано почему); `Remove Worktree…` при
незакоммиченных изменениях показывает их список и требует отдельной галочки `--force`, а
изменения сохраняет в stash. Ворктри с выписанными submodules git без `--force` не удаляет даже
чистым — диалог предупреждает, что их репозитории удалятся вместе с ним, и просит ту же
галочку (R-434). Проверить: удалить ворктри с правкой — правка есть в Stashes; чистый ворктри
после `git submodule update --init` в нём удаляется с галочкой.
