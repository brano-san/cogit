# F-291 · Добавление и удаление ворктри

`Repository ▸ Add Worktree…` открывает диалог: папка, новая ветка с базовым коммитом или
существующая (занятую другим ворктри выбрать нельзя — сказано почему); `Remove Worktree…` при
незакоммиченных изменениях показывает их список и требует отдельной галочки `--force`, а
изменения сохраняет в stash. Проверить: удалить ворктри с правкой — правка есть в Stashes.
