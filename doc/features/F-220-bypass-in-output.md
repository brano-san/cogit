# Обход хуков видно в Output

Каждый коммит с флажком No verify пишет в панель Output отдельную строку с номером коммита, помеченную как предупреждение. Новое сообщение из Edit Message и визуального rebase хуки проверяют, как `reword` в `git rebase -i`; без хуков идут только механические перезаписи: Edit Author (не меняет ни дерево, ни сообщение) и коммиты Split-Off (итоговое дерево то же).
