# Git-Flow без расширения

`Git-Flow: Set Up` пишет те же ключи конфига, что и расширение, и заводит `develop`; старт и завершение feature, release и hotfix идут обычными `branch`, `merge --no-ff` и `tag`, а конфликт при завершении оставляет ветку на месте.

Завершается та flow-ветка, на которой HEAD сейчас: статус перечитывается перед `Finish This Branch…` и после каждого изменения, в том числе checkout в Branches и в терминале; feature сливается и удаляется только после вопроса.
