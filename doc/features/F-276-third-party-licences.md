# F-276 · Список сторонних лицензий

Ссылка `Third-party licences` в About открывает текстовым файлом список крейтов Rust и
npm-пакетов, попавших в сборку, с версией, лицензией и репозиторием каждого; список
составлен при сборке. Проверить: в релизной сборке нажать ссылку — открывается файл с
двумя разделами, `Rust crates` и `Frontend packages`.
