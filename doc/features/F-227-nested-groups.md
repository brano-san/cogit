# Вложенные группы репозиториев

Группу можно перетащить внутрь другой; вложенность рисуется отступом, удаление родителя поднимает детей на его место, а цикл отклоняется.

`Delete this group` сначала спрашивает, называя группу, сколько репозиториев уйдёт в Ungrouped
и сколько групп поднимется на уровень.
