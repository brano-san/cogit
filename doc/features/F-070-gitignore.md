# F-070 · Add to .gitignore

- [ ] Кнопка Ignore у неотслеживаемого файла дописывает его в .gitignore, не дублируя уже имеющиеся строки.
- [ ] У отслеживаемого файла кнопка Ignore в строке Unstaged неактивна, подсказка — «Only an
      untracked file can be ignored»; так же Discard у неотслеживаемого, `+x` у файла без смены
      режима, Delete у удалённого — как пункты меню Files. С отмеченными строками кнопка решает
      за все отмеченные, на которые подействует.
