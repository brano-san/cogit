# F-263 · Цветные линии веток

`Varying Coloring` (Preferences ▸ Graph & History ▸ Coloring или меню настроек справа от
фильтра графа; по умолчанию `Default Coloring`) красит каждую полосу своим цветом; бывшая
настройка `Coloured branch lines`, её значение из старого файла настроек переносится (R-574).
Проверить: выбрать `Varying` — линии разноцветные; `Default` — главная линия цвета текста,
остальные серые.
