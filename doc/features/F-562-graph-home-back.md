# F-562 · «Домой» и «Назад» в графе

- [ ] Справа от фильтра графа две кнопки. «Домой»: с Working Tree — к коммиту HEAD, с HEAD и с любого другого коммита — к Working Tree; выбранная строка показывается в списке (Working Tree — прокруткой к началу). В пустом репозитории с Working Tree неактивна с причиной. Когда строки Working Tree нет (`Show Working Tree Permanently` выключен, изменений нет), «Домой» всегда ведёт к HEAD.
- [ ] «Назад» — к предыдущему выбору в графе этого репозитория (коммит или Working Tree), дальше — ещё раньше, как «Назад» в браузере без «Вперёд»; неактивна с причиной, пока возвращаться некуда. История своя у каждого открытого репозитория, до 100 шагов.
- [ ] Проверить в сборке: выбрать A, потом B → «Назад» — выбран A и виден; ещё раз — Working Tree, кнопка неактивна; «Домой» на Working Tree — HEAD, ещё раз — Working Tree, список вверху; переключиться на другой репозиторий и обратно — история первого на месте.
