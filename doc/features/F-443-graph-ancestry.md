# F-443 · Предки и потомки выбранного коммита

- [ ] С включённым в Preferences режимом у выбранного коммита остаются яркими он сам, его предки и потомки и линии между ними, остальные коммиты и линии приглушены; выбор другого коммита переносит подсветку без мигания, цвета отмеченных веток сохраняются.
