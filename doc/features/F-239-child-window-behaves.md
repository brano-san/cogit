# F-239 · Окно сравнения ведёт себя как окно

- [ ] Окно diff открывается с содержимым, а не белым листом; если содержимое не загрузилось, в окне написано почему.
- [ ] Меню приложения в нём отсутствует: в `Repository ▸ …` нет ничего про один файл.
- [ ] Окно закрывается крестиком, `Esc` и `Ctrl+W`, и не оставляет процесса позади.
- [ ] Развернуть окно — содержимое растягивается вместе с ним, чёрных полей по краям нет.
- [ ] Открыть два окна сравнения, закрыть первое, открыть третье — все открываются, ни одно не отказывает из-за занятого имени.
- [ ] В светлой теме Windows заголовок Compare, Merge, Blame и Investigate тёмный, как у
      главного окна, а не белая полоса над тёмным содержимым.
