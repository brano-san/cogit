# F-066 · Создание Pull Request

- [ ] Палитра открывает в браузере готовую форму PR для GitHub, GitLab или Bitbucket и предлагает сначала запушить ветку.
- [ ] Ветка, отслеживающая одноимённую на remote (`feature` → `origin/feature`), открывает форму в ветку по умолчанию репозитория; заголовок — тема последнего коммита ветки, а не выделенного в графе.
- [ ] Ветка, которой нет на remote, сначала предлагает push; на отсоединённом HEAD пункт неактивен с причиной «HEAD is not on a branch».
