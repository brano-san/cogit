# F-011 · Порядок файлов: сортировка по колонкам таблицы

- [ ] Список Files — таблица (F-571); по умолчанию он идёт по имени файла, щелчок по заголовку
      колонки (Name, Type, State, Path) сортирует по ней, второй щелчок — в обратном порядке;
      у колонки сортировки — стрелка. Порядок один на все списки панели и переживает
      перезапуск. В дереве каталоги идут по пути, сортировка работает внутри каждого (R-595).
