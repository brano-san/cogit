# F-625 · Conflict Solver

Окно `Cogit — Conflict Solver — <файл>` по образцу SmartGit: Ours | Result | Theirs, три CodeMirror,
синхронный скролл, соединители, действия на участок, внешний merge tool. Заменяет прежнее четырёхколоночное
окно слияния (F-505, F-506, F-510 — снято).

- [ ] **Открытие.** Двойной щелчок или `Enter` на файле Conflicted в Files; `Resolve…` в панели
      предпросмотра слияния (Diff) и в подменю `Resolve` контекстного меню файла (неактивно, не скрыто:
      не конфликт или несколько файлов); `Local ▸ Resolve Conflicts…` и палитра «Resolve Conflicts…» —
      для выбранного или первого конфликтного файла. Окно на мониторе главного, без меню, закрывается
      `Esc`, `Ctrl+W`, ✕. Второй вызов для того же файла выводит открытое окно вперёд.
- [ ] **Панели.** Заголовки `<ветка> ("ours")`, `Working Tree`, `<источник> ("theirs")` — из состояния
      операции (merge, cherry-pick, revert, rebase, stash apply: `Stashed changes`). Ours и Theirs — только
      чтение, Result редактируется (подсветка Lezer/CodeMirror, история `Ctrl+Z`/`Ctrl+Y`). Скролл
      синхронный; Aligned — участки одной высоты со штриховкой, Compact — лента кривой. Настройка
      `Preferences ▸ Diff & Merge ▸ Diff View ▸ Side by side ▸ Rows` общая с diff.
- [ ] **Base Changes.** Выключено: цветом `diff.changed.*` отмечены участки, где Ours и Theirs различаются.
      Включено: каждая сторона красится по тому, что сделала с base (`diff.add.*`, `diff.del.*`,
      `diff.changed.*`).
- [ ] **Конфликты.** Нерешённый конфликт в Result — `diff.changed.*` и полоса `status.danger` в гутере,
      пока строки равны base. Счётчик «N conflicts left» в панели и в строке состояния; конфликт,
      правленный вручную или взятый, перестаёт считаться; `Ctrl+Z` возвращает его.
- [ ] **Действия на участок.** `Take Ours`, `Take Theirs`, `Take Ours + Theirs`, `Take Theirs + Ours` — кнопки
      панели, контекстное меню (правый щелчок на любой панели), `Ctrl+1…4`; кнопки `»` (Ours) и `«`
      (Theirs) в полосах между панелями у каждого участка, где результат ещё не равен стороне.
- [ ] **Навигация.** `↑/↓ Change` (`Shift+F6`/`F6`) и `↑/↓ Conflict` (`Shift+F7`/`F7`) идут по кругу;
      «текущий» участок отмечен полосой `selected.bar` во всех панелях и следует за кареткой.
- [ ] **Раскладки.** `Ours + Result`, `All`, `Result + Theirs`, `Result below` (Ours и Theirs сверху,
      Result на всю ширину снизу); выбор и `Base Changes` помнятся (`localStorage`, `cogit:solver`).
- [ ] **Изменён / удалён.** Отсутствующая сторона — пустая панель с плашкой «Deleted in ours/theirs»; Result
      начинается с уцелевшей стороны; `Keep file (ours)`, `Keep file (theirs)` (сторона целиком, `git add`),
      `Delete file` (подтверждение, `git rm`, Undo вернёт), `Save` — оставить файл с правленым Result.
- [ ] **Бинарный и слишком большой (> 4 МиБ) файл.** Объясняющее состояние вместо панелей; только
      `Keep file (ours|theirs)`, `Delete file` и внешний инструмент.
- [ ] **Save.** `Ctrl+S`/кнопка пишет Result (окончания строк и конечный перевод — как у файла) и делает
      `git add`: файл уходит из Conflicted в Staged, окно закрывается, главное обновляется. Нерешённые
      конфликты — вопрос «Save with Conflict Markers» (в файл идут маркеры git); Cancel ничего не пишет.
- [ ] **Закрытие.** С правками в Result — Save / Discard / Cancel (`Esc`, `Ctrl+W`, ✕).
- [ ] **Внешний инструмент.** `Open in external tool` в панели и в меню файла (открывает Solver с запуском).
      Настройка `Preferences ▸ Diff & Merge ▸ Merge Tool`: программа и аргументы с `{base}`, `{ours}`,
      `{theirs}`, `{result}`; пусто — `git config merge.tool`. Пока инструмент открыт, окно заблокировано,
      баннер «Waiting for external tool…» и `Cancel` (завершает инструмент). После выхода: маркеров нет —
      вопрос «Mark Resolved» (`git add`, окно закрывается); маркеры остались — файл остаётся Conflicted.
      Несохранённые правки Solver при запуске теряются (спрашивает).

**Временные файлы инструмента.** `<temp>/cogit-merge/<pid>-<время>-<n>/<имя>.base|ours|theirs<расш>` (пустой
файл для отсутствующей стороны, имя файла как у конфликтного, недопустимые символы Windows → `_`);
`{result}` — сам рабочий файл, как у `git mergetool`. Папка удаляется при любом конце — выход, отмена,
ошибка запуска — до события `merge-tool-finished`; при старте приложения `sweep` убирает папки старше суток
(сбой, убитый процесс). Подробности и решения — [R-685](../12-risks.md).
