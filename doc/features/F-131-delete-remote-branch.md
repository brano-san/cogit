# Удаление удалённой ветки

Удалённую ветку можно удалить на сервере через push --delete, с подтверждением о необратимости.

- Ветка удаляется по полному имени на сервере (`refs/heads/…`, через fetch-refspec remote'а): тег с тем же именем не мешает и остаётся.
- Если ветки на сервере уже нет, это не ошибка: строка пропадает из списка, уведомление — «Branch already deleted» (R-480).
