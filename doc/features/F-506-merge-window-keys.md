# F-506 · Клавиши окна слияния

> **Заменено [F-625](F-625-conflict-solver.md):** окно слияния и выбор сторон в панели Diff убраны; конфликт решает Conflict Solver, предпросмотр в панели только читает.

- [ ] В окне слияния (кнопка ⧉ над панелью слияния) `F6` / `Shift+F6` переходят к следующему /
      предыдущему конфликту; `Ctrl+1`, `Ctrl+2`, `Ctrl+3` берут для текущего конфликта Theirs,
      обе стороны, Ours и переходят к следующему; с `Shift` — для всех конфликтов сразу;
      `Ctrl+S` сохраняет. Цифры работают и в русской раскладке (R-453).
