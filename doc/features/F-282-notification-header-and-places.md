# F-282 · Шапка уведомления не наезжает на счётчик, длинный список сворачивается

Длинный заголовок переносится только в своей колонке и не заходит под `‹ 2 of 2 ›` и
крестик; из списка мест видны первые пять и `and N more`, раскрытый список прокручивается
внутри окна, кнопки внизу видны всегда. Проверить: `core.ignoreCase` на репозитории с
двадцатью подмодулями.
