# Четырёхпанельное слияние

Конфликтный файл открывается в четырёх выровненных панелях — Theirs, Base, Ours и результат, — со счётчиком конфликтов, переходом к следующему и предыдущему, выбором версии для одного конфликта и для всех сразу.

Кнопки theirs / ours / both стоят у каждого конфликта и после выбора: выбранная сторона
подсвечена, другую можно выбрать поверх, `✕` возвращает конфликт в нерешённые. Проверить: три
конфликта, в первом ошибочно выбрать ours, затем theirs, затем `✕` — счётчик unresolved
меняется, остальные выборы на месте.
