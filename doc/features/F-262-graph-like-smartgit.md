# F-262 · Граф как в SmartGit

Главная линия — прямая в левой колонке, остальные линии серые, уплотняются влево и
переходят между колонками S-кривой, а текст строки начинается сразу за её последней линией.
Проверить: открыть репозиторий с несколькими слитыми ветками — после слияния линии правее
сдвигаются влево, у строки с одной линией сообщение стоит у самого края графа.
