# F-064 · Дерево ссылок

- [ ] Ветки с косыми чертами вкладываются в папки, секции сворачиваются кликом по заголовку.
- [ ] У каждого настроенного remote — свой узел со своим меню, в том числе у только что
      добавленного и ещё не полученного (`upstream (0)`). Проверить: `git remote add upstream <url>`
      — узел `upstream (0)` появляется без fetch; после Fetch его ветки — под ним, ветки `origin` —
      под `origin`.
