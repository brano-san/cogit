# F-364 · Index Editor

`Index Editor…` показывает файл в трёх панелях — HEAD (только чтение), Index и Working Tree —
и сохраняет правки индекса и рабочего дерева по отдельности, не трогая нетронутую сторону.
Проверить: вписать строку только в панель Index и сохранить — в Staged diff есть эта строка,
файл на диске прежний.
