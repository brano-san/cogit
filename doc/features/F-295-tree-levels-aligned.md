# F-295 · Уровни деревьев выровнены

Треугольник вложенного элемента стоит ровно под иконкой (в Branches — под чекбоксом) родителя
во всех деревьях. Проверить: раскрыть подмодули в Repositories — треугольник подмодуля под
иконкой репозитория; раскрыть Local в Branches — треугольник папки под чекбоксом Local.
