# F-076 · Подсветка перемещённых блоков

- [ ] Блок от трёх строк, переехавший внутри файла, показывается как перемещение, а не как удаление плюс вставка, независимо от изменившегося отступа.
- [ ] Как у git (`COLOR_MOVED_MIN_ALNUM_COUNT`): блок меньше чем с 20 буквами и цифрами (скобки, пустые строки) — не перемещение, и строки, разделённые неизменённой, в один блок не собираются: `A } B } C } D` → `A B C D } } }` без пунктирной ленты.
