# F-345 · Статус открытия репозитория — только в футере

Пока репозиторий открывается впервые, панели пусты, а «Opening repository…» пишет
только строка активности в футере; слева в футере — имя открываемой папки. Проверить:
запустить Cogit с большим репозиторием в сессии и посмотреть на окно до конца открытия.
