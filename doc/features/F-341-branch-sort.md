# F-341 · Натуральная сортировка и сортировка по дате в Branches

Кнопки рядом с фильтром Branches: натуральная сортировка (включена по умолчанию, `v1.0.2`
раньше `v1.0.10`) и сортировка по дате вершины (новые сверху, старые сверху); выбор
сохраняется между запусками. Проверить: теги `v1.0.2` и `v1.0.10` меняются местами при
выключении натуральной сортировки; по дате — сверху ветка с самым свежим коммитом.
