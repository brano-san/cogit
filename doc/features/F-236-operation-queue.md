# F-236 · Ни одно действие не теряется и не обгоняет другое

- [ ] Три нажатия на push подряд дают три push один за другим, в том порядке, в котором по ним кликнули, а не один выполненный и два потерянных.
- [ ] Пока идёт долгая операция, интерфейс остаётся отзывчивым: окно двигается, панели переключаются, следующее действие встаёт в очередь и видно, что оно ждёт.
- [ ] Операции в разных репозиториях идут одновременно и друг друга не ждут.
- [ ] Если закрыть и снова открыть панель во время длинной операции, очередь видна целиком, а не с середины.
