# F-615 · Выделение нескольких коммитов и веток, Ctrl+A

- [ ] **Одна модель выделения** (`lib/item-selection.ts`) в Graph и Branches: клик — одна строка;
      `Ctrl`+клик — добавить / снять; `Shift`+клик — диапазон от якоря (в Branches по видимому порядку
      дерева, свёрнутые группы не захватываются); `Shift`+стрелки, `PageUp/Down`, `Home/End` — расширить;
      `Ctrl+A` — все видимые; ПКМ по невыделенной строке заменяет выделение ею, по выделенной —
      меню всей группы. Строки — `bg.selected` и полоса `selected.bar`, в неактивной панели
      `bg.selectedInactive` (общий `Panel`).
- [ ] **Graph.** Выделение хранится как oid; диапазон читается по строкам между якорем и целью
      (`lib/graph-selection.ts`, предел 5000 строк). Files и Diff показывают последний выбранный
      коммит. Меню группы (`lib/ref-selection.ts`, `SelectionActions.svelte`): Cherry-Pick… (от старого
      к новому, один `git cherry-pick <oid…>`), Revert… (от нового к старому), Copy Message (через
      пустую строку, в порядке графа), Copy ID (полные хэши по одному); остальные пункты видны и
      неактивны с причиной. Остановка на конфликте — прежним окном ошибок и баннером состояния.
- [ ] **Branches.** Меню группы: Push To… (один диалог для всех локальных веток), Delete… (список в
      подтверждении, текущая ветка и ветки чужого worktree исключены с объяснением, remote-ветки —
      `push --delete` с отдельным предупреждением, теги), Copy (имена по одному на строку),
      Toggle (`Space`) — видимость в графе у всех выбранных; остальное неактивно.
- [ ] **Ctrl+A** — один обработчик окна (`lib/select-all.ts`): всегда `preventDefault`, кроме полей
      ввода, `textarea`, `contenteditable` и CodeMirror. Действие передаётся активной панели (`focused`):
      Repositories, Branches, Files, Graph — все видимые строки; Diff и сведения о коммите — текст
      стороны, где кликнули; вывод команд — сам; остальные панели — ничего. Отдельные окна получают
      тот же обработчик через `installChildWindow`.
- [ ] `user-select: none` для списков и панелей инструментов (`role` tree / listbox / toolbar /
      tablist / menu), текст открыт точечно: код diff, вывод, сведения о коммите, заметки.
- [ ] Тесты: `item-selection`, `select-all` (правила диспетчера), `graph-selection`, `ref-selection`
      (меню, порядок, удаление), `ref-delete-run`, `push-branches`. Новых команд IPC нет.
