# F-370 · Поиск по содержимому файлов

- [ ] В Working Tree кнопка `⌕` в поле фильтра Files включает поиск по содержимому: список сужается до файлов, в которых есть введённый текст (с `*` — регулярное выражение), под полем видно «Searching file contents…», затем «Found in N files»; с включённой кнопкой `Unchanged` ищется по всем файлам репозитория, без неё — по изменённым.
