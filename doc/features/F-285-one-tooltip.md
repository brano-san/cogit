# F-285 · Подсказки везде одинаковые

Любая подсказка в приложении — кнопки тулбара, маркеры `M`/`A`/`?` в Files, иконки типа,
метки `ahead`/`not fetched`/`missing` в Repositories — появляется через одинаковые 400 мс в
одном и том же пузыре и объясняет, что значит элемент. Проверить: навести на `M` в Files —
«Modified — changed since last commit».
