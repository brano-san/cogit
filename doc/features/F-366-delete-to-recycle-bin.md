# F-366 · Delete — в Корзину

`Delete…` в меню файла и кнопка `Delete` над списком Unstaged после подтверждения переносят
файлы в Корзину (на Linux и macOS — в корзину рабочего стола), а не удаляют безвозвратно.
Тесты на Windows — `src-tauri/src/recycle_bin.rs`: файл после переноса исчезает из папки,
отказ оболочки приходит ошибкой. Проверить в сборке: удалённый файл лежит в Корзине и
восстанавливается оттуда.
