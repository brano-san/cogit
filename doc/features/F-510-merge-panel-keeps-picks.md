# F-510 · Панель слияния не теряет выбранные стороны

- [ ] Открыть конфликтный файл в Files, выбрать стороны у нескольких конфликтов, затем
      щёлкнуть тот же файл ещё раз (или дважды) — выборы и ручная правка на месте.
- [ ] С выбранными сторонами щёлкнуть другой файл в Files — вопрос «Discard the Resolution»;
      Cancel оставляет слияние с выборами, Discard открывает другой файл. Без выборов другой
      файл открывается сразу.
