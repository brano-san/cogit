# F-063 · Палитра команд

- [ ] Ctrl+Shift+P открывает нечёткий поиск по всем действиям; недоступные показываются с причиной, а не прячутся.
- [ ] ↑/↓ прокручивают список за подсвеченной строкой: 25 раз ↓ в пустом запросе — строка на
      виду, Enter запускает видимую команду.
- [ ] Первыми в пустом запросе стоят команды, запущенные из палитры; сама `Find Command` и
      команды из меню и его клавиш туда не попадают: Ctrl+Shift+P, Esc, Ctrl+Shift+P — первой
      не «Find Command».
