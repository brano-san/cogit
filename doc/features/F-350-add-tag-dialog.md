# F-350 · Диалог Add Tag

Кнопка `Tag` в тулбаре, `Add Tag` в меню коммита или метки графа открывают диалог: имя,
многострочное сообщение и коммит (короткий хеш + тема), на который встанет тег. Проверить:
пустое сообщение — лёгкий тег, непустое — аннотированный; имя `a..b` или уже занятое —
ошибка под полем, диалог не закрывается.
