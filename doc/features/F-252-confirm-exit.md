# F-252 · Выход спрашивает, а посреди push — предупреждает

Крестик, `Alt+F4` и `Repository ▸ Exit` (`Alt+X`) показывают диалог Exit с «Don't show
again»; пока push, pull или fetch идут или ждут, диалог появляется всегда и перечисляет
их. Проверить: поставить галочку, выйти, открыть `Preferences ▸ General` — «Confirm before
exiting» снят, а в `User Interface ▸ Behavior` есть строка с «Show again» (R-169).

Выход закрывает и открытые Blame, Compare, Investigate: без главного окна процесс больше не
живёт с одним дочерним. Merge с несохранённым выбором спрашивает сам и может остаться — тогда
приложение выходит, когда закроют и его. Проверить: открыть Blame, `Alt+X` ▸ Exit — окна нет,
`cogit.exe` в диспетчере задач нет.
