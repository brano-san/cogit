# F-234 · Проверка обновлений, которая не включается сама

- [ ] Help ▸ Check for Updates… сообщает, что обновлений нет, либо предлагает поставить найденное и перезапустить; галочка в Settings ▸ Advanced ▸ Updates включает ту же проверку при старте, и по умолчанию она снята.

Install сначала задаёт вопросы выхода: несохранённый хук или разрешение конфликта — «Restart anyway?», идущие операции — окно Exit (Cancel, Exit When Done, Exit Anyway); отказ ничего не ставит.
