# F-014 · Навигация по ханкам

- [ ] F6 и Shift+F6 прыгают к следующему и предыдущему изменению, пока фокус в панели Diff
      (щелчок в ней). За последним изменением F6 переводит фокус на следующую панель.
- [ ] Фокус в Graph, открыт diff файла → F6: фокус на следующей панели, diff не прокрутился.
      Щелчок в поле сообщения коммита → Ctrl+F: поиск diff не открывается.
