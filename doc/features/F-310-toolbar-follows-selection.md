# F-310 · Кнопки тулбара следуют выбору

Stage, Unstage и Discard включаются по выбору файлов в Files на Working Tree, Merge и
Rebase — по выбранному в Graph или Branches коммиту. Проверить: выбрать Working Tree с
изменённым файлом — Stage активна; выбрать в графе ветку, отошедшую от HEAD, — активны
Merge и Rebase; выбрать предка HEAD — Merge неактивна, Rebase активна; навести на
неактивную кнопку — подсказка называет причину.
