# F-521 · Update в меню строки submodule

- [ ] Submodule отстал от записанного коммита (`behind`): ПКМ по его строке в Repositories ▸
      Update — `git submodule update` без вопроса, строка становится без пометки.
- [ ] Submodule ушёл вперёд или разошёлся (`ahead`, `diverged`): Update спрашивает в общем
      модальном окне, сколько своих коммитов у submodule и где они останутся (на ветке или ни
      на какой — только в reflog); Cancel ничего не меняет, Update переключает на записанный
      коммит.
- [ ] Неинициализированный: Update инициализирует и извлекает его.
- [ ] Уже на записанном коммите, записанный коммит не получен, строка чужого репозитория, ещё
      не прочитанная, и строка самого репозитория — Update неактивен и в подписи сказано почему.
- [ ] Подсказка отставшей строки называет Update в её меню.
