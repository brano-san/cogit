# F-059 · Подсветка синтаксиса

- [ ] Diff подсвечивает синтаксис для Rust, C/C++, JS/TS, Python, JSON, CSS и HTML, не перебивая заливку изменений.
- [ ] Rust-файл, в котором изменена строка посреди функции (ханк начинается внутри неё): в обеих
      колонках `fn`, имена полей, типы и строки окрашены так же, как в целом файле; токен не
      делится на части разного цвета (R-530).
- [ ] Изменённое слово с ключевым словом внутри (`let` → `const`): фон изменения есть, цвет
      ключевого слова сохранён.
- [ ] Файл больше 5000 строк: подсветка есть, как раньше, по загруженным и показанным строкам.
