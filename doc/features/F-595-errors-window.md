# F-595 · Ошибки команд — отдельное окно

- [ ] **Сбой команды git** не показывает тост: сразу открывается окно `Cogit — Errors` на мониторе
      главного окна с полным выводом, как у `Show Output`: Command, Exit code, Duration, Started,
      вывод, `Wrap lines`, `Open log`, `Copy output`, `Close`; в шапке и в полях — репозиторий и
      команда самой операции.
- [ ] **Закрытие.** ✕, `Esc`, `Ctrl+W`, `Close` и системная кнопка закрывают окно; закрытие убирает
      всё, что в нём было. `Dismiss` убирает одну запись и показывает следующую.
- [ ] **Несколько ошибок подряд** — одно окно: слева список (заголовок, репозиторий, `×N` у
      повторов), справа вывод выбранной. Новые окна не открываются, открытое окно выходит вперёд
      без кражи фокуса.
- [ ] **Частичный успех.** `stash apply/pop`, `merge`, `rebase`, `cherry-pick`, `revert`, `pull`,
      `am`, закончившиеся конфликтами (код выхода 1 и unmerged-записи в индексе), — предупреждение:
      «Stash applied with conflicts» / «Merge stopped with conflicts», маркер `status.warning`, кнопка
      `Show conflicts` (главное окно выходит вперёд, открывается первый конфликтный файл).
- [ ] **Сырой вывод** не меняется (INV-05); учётные данные в URL скрываются, как раньше.
- [ ] **Футер.** `Error` горит, пока в очереди есть ошибки; предупреждение его не зажигает.
- [ ] **Для панели задач:** `errorWindow.errorCount`, `unviewed`, `unviewedErrors`, `warningPresent`
      (`$stores/error-window`).

Не git-ошибки (диффа, настроек, предупреждения репозитория) по-прежнему в окне уведомлений
`Notifications`. Решения и ограничения — [R-645](../12-risks.md).
