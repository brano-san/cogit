# F-258 · Граф — история отмеченных ссылок

По умолчанию отмечен только HEAD; отметка ветки или тега добавляет в граф её историю, а
метки всех ссылок видны на любом нарисованном коммите без отметок. Аннотированный тег
отмечается без ошибки; тег не на коммит неактивен. Проверить: отметить аннотированный тег на
коммите вне истории HEAD — коммит и его история появляются в графе.
