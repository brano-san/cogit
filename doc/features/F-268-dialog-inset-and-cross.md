# F-268 · Диалоги: одна левая линия, один крестик, Enter на кнопке

В About, Exit и Edit Git Config заголовок окна, содержимое и нижняя панель начинаются на
одной левой линии, крестик в заголовке серый и светлеет при наведении, кнопки прижаты
вправо, основная — крайняя справа. Проверить: открыть Exit, нажать Tab до Cancel и Enter —
диалог закрывается, Cogit остаётся.
