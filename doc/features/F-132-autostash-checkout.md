# Автостэш при переключении

Если git отказал в checkout из-за локальных изменений — при любом варианте диалога Checkout
(F-555), — Cogit предлагает перенести их: диалог с файлами, которые назвал git, чекбоксом
«Drop the stash once it applies cleanly» (включён) и кнопкой `Stash and Check Out`. Для
пользователя — «перешёл на другую ветку вместе со своими изменениями» (п. 46 списка 25.09).

Stash, checkout и `stash apply` — одна операция очереди репозитория (`switch_with_autostash`,
R-521, R-563). Пока она идёт, stash вне списка (`refs/cogit/backup`), и stash-и пользователя не
сдвигаются. Применился чисто — stash удалён (с выключенным чекбоксом — остаётся в списке как
`stash@{0}`, об этом сообщение); с конфликтами — остаётся в списке, в уведомлениях — вывод git
и сообщение «Changes did not apply cleanly». Если checkout отказал и после stash, изменения
возвращаются как были, staged — staged, уведомление — отказ git.
Тесты — `git_engine` `tests/autostash.rs`, `checkout-flow.test.ts`.
