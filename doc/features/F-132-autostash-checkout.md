# Автостэш при переключении

Если git отказал в checkout из-за локальных изменений, Cogit предлагает спрятать их, переключиться и вернуть обратно.

Если checkout отказал и после stash, изменения возвращаются из только что сделанного stash; не вернулись — уведомление называет `stash@{0}`. Тест — `autostash.test.ts`.
