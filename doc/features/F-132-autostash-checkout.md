# Автостэш при переключении

Если git отказал в checkout из-за локальных изменений, Cogit предлагает спрятать их, переключиться и вернуть обратно.

Stash, переключение и возврат — одна операция очереди репозитория (`switch_with_autostash`,
R-521): изменения возвращаются из того stash, что сделан для них, даже если в списке он уже не
первый. Если checkout отказал и после stash, изменения возвращаются, уведомление — отказ git;
не вернулись — вывод `git stash pop` в уведомлениях, stash остаётся. Тесты — `git_engine`
`tests/autostash.rs` и `autostash.test.ts`.
