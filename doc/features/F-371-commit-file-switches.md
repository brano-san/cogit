# F-371 · Переключатели Files в коммите из истории

- [ ] При выбранном коммите в тулбаре Files работают только `Unchanged` (показывает остальные файлы дерева коммита), `Missing/Removed` (в коммите — исходные файлы распознанных переименований) и дерево/плоский список; остальные кнопки бледные, не подсвечиваются и не нажимаются, tooltip объясняет почему; вернувшись в Working Tree, видишь прежнее состояние всех кнопок.
