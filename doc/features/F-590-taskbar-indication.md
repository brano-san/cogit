# F-590 · Индикация на панели задач

- [ ] **Прогресс.** Пока идёт fetch, push, pull или clone, кнопка Cogit на панели задач показывает
      полосу: процент, если Git его печатает (`Receiving objects: 45%`), иначе бегущую. Снимается
      по завершении.
- [ ] **Ошибка.** Пока в окне уведомлений есть ошибка — красная полоса и красный `!`; окно не в
      фокусе — кнопка мигает до фокуса. Снимается, когда ошибки закрыты.
- [ ] **Предупреждение.** Пока есть неразрешённые конфликты — жёлтый `!` (идущий прогресс не
      скрывается) и мигание в фоне.
- [ ] **Успех в фоне.** Фоновая операция закончилась, окно не в фокусе — короткое мигание без значка.
- [ ] **Несколько событий.** Два и больше непросмотренных — значок с числом (`9+` после девяти).
      Фокус окна сбрасывает.
- [ ] **Приоритет.** error > warning > progress.
- [ ] **Настройки.** `Preferences ▸ User Interface ▸ Notifications`: `notificationsTaskbar` (всё
      вместе) и `notificationsTaskbarFlash` (только мигание), оба включены.
- [ ] **Платформы.** Реализовано для Windows; Linux и macOS — заглушка (R-638).

Код: `crates/app_state/src/taskbar.rs`, `src-tauri/src/taskbar/`, `set_taskbar_state`,
`frontend/src/stores/taskbar.svelte.ts`, `frontend/src/lib/taskbar.ts`.
