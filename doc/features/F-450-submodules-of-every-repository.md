# F-450 · Submodules любого репозитория без активации

Треугольник у каждой строки Repositories — открытой, неактивной или закрытой — раскрывает её
submodules, не делая репозиторий активным: дерево читается лёгким способом, из `.gitmodules` и
gitlink-записей. Раскрытыми можно держать несколько проектов сразу; клик по submodule любого
проекта открывает его в панелях одним действием (проект при этом открывается в фоне).
Раскрытые деревья и узлы переживают перезапуск. Проверить: раскрыть submodules двух
неактивных репозиториев, один из них закрытый; кликнуть submodule закрытого — он в панелях,
проект в списке без приглушения; перезапустить Cogit — деревья раскрыты как были.
