# F-290 · Устаревший ворктри: Prune или Repair прямо в строке

У ворктри с меткой `missing` в строке есть `Prune` (забывает регистрацию после
подтверждения, на диске ничего не трогает) и `Repair` (спрашивает, где папка теперь, и
выполняет `git worktree repair`); `Prune All` в заголовке активна, только когда такие есть.
Repair идёт в общей очереди: в футере `Repairing worktree <name>…`, по окончании —
уведомление `Worktree repaired` или ошибка. Заодно он обновляет stat-кэш индекса, чтобы
следующие чтения не перечитывали каждый файл перенесённой папки (R-360).
Проверить: перенести папку ворктри на другой диск, нажать `Repair` и выбрать новую папку —
статус в футере, уведомление, список обновился быстро.
