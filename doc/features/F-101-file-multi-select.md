# F-101 · Мультивыбор файлов

- [ ] Ctrl+клик и Shift+клик выделяют несколько файлов, пробел добавляет файл под курсором, и любое действие в строке применяется ко всему выделению.
- [ ] Частично проиндексированный файл стоит в Unstaged и в Staged: щелчок подсвечивает только
      ту строку, чей diff открыт, отметка одной строки не отмечает другую, Shift+клик отмечает
      диапазон только в своей секции, а кнопка строки действует на отмеченные строки своей секции.
      Так же Stage и Unstage в тулбаре и контекстное меню: такой файл, отмеченный в Unstaged,
      Unstage тулбара не трогает.
