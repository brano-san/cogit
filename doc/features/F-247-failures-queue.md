# F-247 · Отказ git не теряется в очереди

- [ ] Три разных отказа подряд дают одно окно с навигацией «‹ 1 of 3 ›»; `Close` показывает следующий, окно закрывается на последнем.
- [ ] Пятнадцать одинаковых отказов `pull` — одна запись со счётчиком `×15`.
- [ ] `Copy output` кладёт в буфер команду, код возврата, длительность, время запуска, репозиторий и весь вывод.
- [ ] Выделять можно всё поле вывода, включая пустое место справа от строк и под последней строкой.
- [ ] `Wrap lines` переключает перенос, `Open log` открывает папку логов.
