# F-524 · Меню кнопок тулбара в узком окне и с клавиатуры

- [ ] Сузить окно до появления «…»: подписи кнопок пропадают, у Pull, Push, Sync, Stash и
      Rebase остаётся каретка, и её меню (Push To…, Fetch '<remote>', порядок Sync, Stash
      Selection, Interactive Rebase…) открывается как в широком окне. Медленно менять ширину
      у границы — «…» и подписи не мерцают.
