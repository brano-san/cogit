# F-571 · Таблица Files: имя, тип, состояние, путь

- [ ] Files — таблица из четырёх колонок: имя (с иконкой, источником переименования), тип
      (`File`, `Repository` — submodule, `Binary`, `Link`, `Folder`), состояние (`M`, `?`, `D`…,
      `+x`) и путь к папке; пути всех строк начинаются с одной вертикали, над списком —
      заголовки колонок. Проверить: изменить `logo.png`, submodule и `src/a.rs` — типы
      `Binary`, `Repository`, `File`; в дереве колонки пути нет, путь — у строк папок (R-595,
      R-596). Список из тысяч файлов прокручивается так же плавно, как раньше.
