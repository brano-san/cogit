# F-545 · Изменения, push и pull у submodules в Repositories

У каждого узла submodule в дереве Repositories — у выбранного проекта и в лёгких деревьях
остальных, открытых и закрытых, — те же метки, что у строки репозитория (F-451): слот точки
«есть изменения» слева от имени и стрелки push и pull на углах иконки submodule, числа — в
подсказке иконки. Метки не зависят от выбора: submodule, который показывают панели, берёт
их из того, что панели держат свежим, любой другой — из фонового чтения по своей папке
(R-542). Не выписанный submodule меток не имеет — читать там нечего. Коммит внутри
submodule, сделанный в терминале, родитель на экране слышит сразу (R-541); узлы остальных
деревьев перечитываются при возврате фокуса окну. Узлы читаются, когда дерево 1,5 с не
перечитывалось (R-617): метки после открытия или записи приходят с этой задержкой.
Проверить: у проекта с submodule изменить файл внутри submodule — точка у узла submodule и у
проекта; сделать коммит внутри submodule в терминале — у узла стрелка вверх, если у его ветки
есть upstream; выбрать submodule и вернуться к проекту — точка у submodule не пропадает;
раскрыть submodules закрытого проекта — у выписанных узлов точки по их состоянию.
