# F-261 · Всё свёрнуто при запуске

Branches и группы Repositories открываются свёрнутыми; раскрытое помнится, пока Cogit
работает. **Деревья submodules — заменено [F-450](F-450-submodules-of-every-repository.md):**
раскрытые деревья и узлы переживают перезапуск (R-352). Проверить: раскрыть Local и группу
Repositories, переключиться на другой репозиторий и обратно — раскрыто; перезапустить Cogit —
Branches и группы свёрнуты, деревья submodules раскрыты как были.
