# F-361 · Закрытый репозиторий остаётся в списке

`Close Repository` (или ✕ в строке) оставляет строку в Repositories приглушённой, с пометкой
`closed`; клик по ней открывает репозиторий снова, `Remove…` убирает из списка, ничего не
удаляя с диска; `Rename…` и `Pin` переживают перезапуск. Проверить: закрыть, перезапустить
Cogit — строка на месте и закрыта; переименовать — меняется только подпись, папка прежняя.
