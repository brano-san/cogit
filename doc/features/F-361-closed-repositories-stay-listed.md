# F-361 · Закрытый репозиторий остаётся в списке

`Close Repository` (только из контекстного меню или `Ctrl+W`, крестика в строке нет) оставляет
строку в Repositories приглушённой — текст и иконка, без надписи; открытый репозиторий, даже
неактивный, не приглушён: переключение на другой его не закрывает. Клик по закрытой строке
открывает репозиторий снова, `Remove…` убирает из списка, ничего не удаляя с диска; `Rename…`
и `Pin` переживают перезапуск. Проверить: открыть два репозитория, переключиться — оба без
приглушения; закрыть один через меню — приглушён; перезапустить Cogit — строка на месте и
закрыта; переименовать — меняется только подпись, папка прежняя.

`Ctrl+W` — то же, что `Close Repository` у строки, которую показывают панели: на экране
следующий открытый репозиторий, а из submodule или worktree — возврат к его репозиторию.
Проверить: открыть A и B, активен A, `Ctrl+W` — на экране B; открыть submodule, `Ctrl+W` —
на экране его репозиторий.
