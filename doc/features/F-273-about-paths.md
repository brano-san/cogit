# F-273 · Пути в About обрезаются посередине

Путь к папке логов и к файлу настроек стоит в одну строку, лишние папки из середины
заменены на `…`, полный путь — во всплывающей подсказке; клик по пути или по иконке-папке
рядом (подсказка `Open log folder`) открывает папку в файловом менеджере. Проверить:
навести на путь — подсказка с полным путём; нажать иконку — открывается папка с выделенным
логом текущего запуска.
