# F-585 · Diff side-by-side на блочной модели: панели, соединитель, подписи

Окно Diff и панель Diff Preview рисуют side-by-side по блочной модели (08 §12), как SmartGit:

- **Панели.** У каждой стороны свой список строк подряд, со своими номерами, без filler и штриховки.
  Цвет по смыслу блока: слева удалённое (`diff.del.*`), справа добавленное (`diff.add.*`),
  перемещённое — `diff.move.*`; слова (`blockInline`) — оверлей `*.word` над фоном строки, синтаксис
  сохраняется. Янтарного «изменено» нет. Unified — те же блоки: сначала удалённые строки, затем
  добавленные, цвета те же.
- **Соединитель.** Одна полоса на блок в центральном гутере (`blockConnectors`): заливка
  `diff.connector.fill`, контур `diff.connector.stroke`, перемещённый блок — цвета `diff.move.*`.
  Координаты пересчитываются при каждом событии прокрутки любой панели и при изменении размера или
  сворачивании. Пустая сторона схлопывается в точку вставки.
- **Кнопки.** Один набор на блок: `»` (вернуть удалённые строки / снять их удаление из индекса) и `×`
  (убрать добавленные / снять их из индекса), строго по центру гутера, по вертикали — по центру видимой
  части соединителя. Серые (`diff.centerGutter.action`), при наведении `…action.hover`, без фона. Нет у
  diff коммита и сравнения и у перемещённых блоков. Select / Stage / Unstage / Discard остались только
  в шапке ханка (полоса «N lines hidden», справа) — при наведении на строки ничего не появляется.
- **Синхронная прокрутка.** Левая панель без собственной полосы, правая с полосой; прокрутка любой
  панели или колесо над гутером двигает обе (`diff-sync`); эхо собственной записи гасит `ScrollGuard`.
  Свёрнутая зона — одна строка высотой в строку кода в обеих панелях; раскрытие пересобирает модель.
- **Подписи панелей** (`sideCaptions`): `Index` / `Working tree`, `HEAD` / `Index`, короткий хэш коммита
  и его родителя, `No parent` у корневого коммита. Мелкая надпись «Working tree vs index» справа сверху
  убрана; полный путь — только в шапке окна. Заголовок окна — `Cogit — <имя файла>` (задаётся через
  `setTitle`, нужен `core:window:allow-set-title`).
- **Переключатели** Whitespace, Moves, Unified, Find — `aria-pressed`, включённое состояние токенами
  `toggle.on.*` (глобальное правило `[aria-pressed]` в `app.css`). Blame и Investigate открывают окна и
  состояния не имеют — обычные кнопки. `LF → CRLF` — бейдж `badge.warning.*` с подсказкой, не кнопка.

Тесты: `diff-blocks`, `diff-inline`, `diff-band`, `diff-sync`, `diff-golden`, `diff-scroll-guard`,
`compare-params` (подписи и заголовок), `diff-toolbar` (бейдж). Проверено в браузере со стендом на
золотом примере `algo_task.cpp` в четырёх темах; прокрутка панелей разной высоты, свёрнутая зона,
unified, чистые add/remove, блок наполовину за экраном.
