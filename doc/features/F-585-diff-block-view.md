# F-585 · Diff side-by-side на блочной модели: панели, соединитель, подписи

Окно Diff и панель Diff Preview рисуют side-by-side по блочной модели (08 §12), как SmartGit:

- **Два режима side-by-side** (`diffLayout`, кнопка **Aligned** в панели Diff и Preferences ▸ Diff View ▸ Rows; по умолчанию Aligned,
  запоминается). **Aligned** — панели 1:1: слева и справа строки на одном уровне, где у стороны нет строки — filler с тонкой
  диагональной штриховкой (`diff.filler.*`, без номера и знака, не выделяется, не копируется, не ищется); похожие строки
  `changed`-блока стоят друг напротив друга (08 §12.2), соединитель — прямая полоса, прокрутка общая. **Compact** — режим,
  описанный ниже (SmartGit): свои строки подряд, без filler, кривые соединители. Unified от режима не зависит.
- **Панели (Compact).** У каждой стороны свой список строк подряд, со своими номерами, без filler и штриховки.
  Цвет по смыслу блока: `removed` — слева `diff.del.*`, `added` — справа `diff.add.*`, **`changed` — обе стороны
  оранжевым `diff.changed.*`, все строки блока (R-629)**, перемещённое — `diff.move.*`; слова (`blockInline`) — оверлей `*.word` над фоном строки, синтаксис
  сохраняется. Unified — те же блоки: сначала удалённые строки, затем
  добавленные, красные и зелёные.
- **Соединитель.** Одна полоса на блок в центральном гутере (`blockConnectors`): заливка
  `diff.connector.fill`, контур `diff.connector.stroke`, перемещённый блок — цвета `diff.move.*`, `changed` — `diff.changed.line` / `diff.changed.word`.
  Координаты пересчитываются при каждом событии прокрутки любой панели и при изменении размера или
  сворачивании. Пустая сторона схлопывается в точку вставки.
- **Кнопки.** Один набор на блок: `»` (вернуть удалённые строки / снять их удаление из индекса) — в левой части
  гутера, `×` (убрать добавленные / снять их из индекса) — в правой; обе по вертикали по центру видимой части
  соединителя на своём x (нет полосы на экране — нет кнопки). `removed` — только `»`, `added` — только `×`; **`changed` — только `»` по центру гутера, действие над всем блоком** (удалённые и добавленные строки одной операцией, одно подтверждение; в индексе — Unstage блока; R-629). Серые (`diff.centerGutter.action`), при наведении `…action.hover`, без фона. Нет у
  diff коммита и сравнения и у перемещённых блоков. Select / Stage / Unstage / Discard остались только
  в шапке ханка (полоса «N lines hidden», справа) — при наведении на строки ничего не появляется.
- **Staged-diff (HEAD ↔ Index).** Только `Unstage lines` в тулбаре и `Unstage` на ханке (`Stage` там неприменим). `Discard lines`, `Discard` на ханке и `»`/`×` в гутере **скрыты** (`bandAction`): в индексном виде Discard либо дублирует Unstage, либо молча уничтожает правки рабочего дерева, которых в этом diff не видно. Working tree ↔ Index — как раньше (`Stage`, `Discard`, `»`/`×` = Discard).
- **Discard всех строк нового файла** (`oldTotal = 0`, выбраны все `i:`-строки, `discardsWholeNewFile`): подтверждение говорит «The file will be deleted from disk».
- **Файл исчез с обеих сторон** (удалён с диска, в индексе не было; ядро отвечает «is absent from both sides of the diff» для `workTreeVsIndex`/`indexVsHead`/`commitVsWorkTree`): `diff.gone` — спокойная надпись «File deleted» (`text.secondary`), не ошибка; refresh и `reload` больше не запрашивают diff; отдельное окно закрывается. Повторный клик по файлу читает заново. Для коммитов это по-прежнему ошибка.
- **Повторы ошибок:** `errors.report(error, title, source)` — одна и та же ошибка одной операции для одного источника (путь) не показывается, пока она в очереди, и 10 с после закрытия.
- **Синхронная прокрутка.** Левая панель без собственной полосы, правая с полосой; прокрутка любой
  панели или колесо над гутером двигает обе (`diff-sync`); эхо собственной записи гасит `ScrollGuard`.
  Свёрнутая зона — одна строка высотой в строку кода в обеих панелях; раскрытие пересобирает модель.
- **Подписи панелей** (`sideCaptions`): `Index` / `Working tree`, `HEAD` / `Index`, короткий хэш коммита
  и его родителя, `No parent` у корневого коммита. Мелкая надпись «Working tree vs index» справа сверху
  убрана; полный путь — только в шапке окна. Заголовок окна — `Cogit — <имя файла>` (задаётся через
  `setTitle`, нужен `core:window:allow-set-title`).
- **Переключатели** Whitespace, Moves, Aligned, Unified, Find — `aria-pressed`, включённое состояние токенами
  `toggle.on.*` (глобальное правило `[aria-pressed]` в `app.css`). Blame и Investigate открывают окна и
  состояния не имеют — обычные кнопки. `LF → CRLF` — бейдж `badge.warning.*` с подсказкой, не кнопка.

Исправления Compact (R-628): подход к концу файла без скачка второй панели; кнопки привязаны к своей полосе; размер панелей
перечитывается `ResizeObserver`-ом. Тесты: `diff-align`, `diff-aligned`, `diff-blocks`, `diff-inline`, `diff-band`, `diff-sync`, `diff-golden`, `diff-scroll-guard`,
`compare-params` (подписи и заголовок), `diff-toolbar` (бейдж). Проверено в браузере со стендом на
золотом примере `algo_task.cpp` в четырёх темах; прокрутка панелей разной высоты, свёрнутая зона,
unified, чистые add/remove, блок наполовину за экраном.
