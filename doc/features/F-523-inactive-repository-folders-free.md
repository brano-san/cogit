# F-523 · Папки неактивных репозиториев не заняты

- [ ] Открыть A и B (A и B лежат в общей папке `projects`), переключиться на B. В Проводнике
      переименовать папку A, убрать её в Корзину или перенести на другой диск — получается;
      на время пока Cogit показывает A — нет (папку показанного репозитория держит
      наблюдатель, R-351).
- [ ] Показать репозиторий из другой папки — `projects` переименовывается.
- [ ] Показывая B, сделать коммит в A из терминала и вернуться в Cogit — строка A в
      Repositories обновляется (сразу по фокусу окна или в конце минуты после прошлого
      чтения); щелчок по A — граф, Files и статус уже с этим коммитом.
