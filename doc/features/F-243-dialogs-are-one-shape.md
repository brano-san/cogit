# F-243 · Все диалоги выглядят и ведут себя одинаково

- [ ] `Add a group`, `Scan folder for repositories` и `Preferences` — тёмный фон темы, крестик в заголовке, `Esc` отменяет, `Enter` подтверждает.
- [ ] В `Preferences` нет ни одного контрола, нарисованного Windows: выпадающие списки, кнопки, галочки и поля — приложения.
- [ ] `OK` выглядит как основное действие, а не как выключенный элемент.
- [ ] Смена темы видна сразу, `Cancel` возвращает всё как было, `OK` сохраняет.
- [ ] Вложенная галочка гаснет вместе с той, под которой она нарисована.
- [ ] `Open 0 Selected` не бывает: пока ничего не отмечено, кнопка говорит, чего ждёт, и выключена.
