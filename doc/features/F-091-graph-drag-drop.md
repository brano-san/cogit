# F-091 · Перетаскивание в графе

- [ ] Ветку можно бросить на ветку (меню Merge / Rebase onto / Fast-forward), а коммит на коммит (Squash или Move), причём каждое переписывание истории требует подтверждения.

Перетаскивание идёт на pointer-событиях (R-450): HTML5 drag-and-drop в WebView2 не доходит
до страницы, пока окно принимает брошенные папки (F-154). Проверить: протащить коммит графа
на другой коммит — у точки отпускания меню Squash / Move; ветку в Branches на другую —
Merge / Rebase onto; короткий щелчок по строке по-прежнему выбирает её.
