# F-232 · Аватары спрашивают, а не включаются сами

**Заменено [F-251](F-251-avatars-on-by-default.md):** аватары включены по умолчанию (Gravatar,
R-145); отключаются в Preferences.

Было: настройка аватаров начиналась в состоянии «не решено» — пока пользователь не выберет в
Preferences, ни одного запроса не уходило и каталог кэша не создавался.
