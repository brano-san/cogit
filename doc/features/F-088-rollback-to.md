# F-088 · Rollback-To

- [ ] Пункт `Roll Back Tree` контекстного меню коммита в графе (после подтверждения) возвращает содержимое выбранного коммита в рабочий каталог как обычные незакоммиченные правки: HEAD не двигается, detached HEAD не возникает, а текущие изменения предварительно уходят в stash.
- [ ] `Undo` возвращает пути такими, какими они были до отката — с прежними правками или без них: откат уходит в stash `cogit: before undoing a rollback`, затем применяется stash прежних правок (R-430).
