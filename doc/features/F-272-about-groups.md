# F-272 · About разбит на группы

Help ▸ About Cogit показывает строки в четырёх группах с приглушёнными подзаголовками —
Application (Version, Commit, Built, Updates), Environment (OS, Renderer, Git), Built with
(Rust, Tauri, Svelte, gitoxide), Files (Log folder, Settings file) — все значения в
коротком формате вроде `1.98.1`. Проверить: открыть About — подписи `Cogit`, `Platform`,
`WebView2` исчезли, `OS` звучит как `Windows 11 24H2 (build 26100), x86_64`, `Renderer` —
как `WebView2 <версия>`.
