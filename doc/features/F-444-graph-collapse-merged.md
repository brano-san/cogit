# F-444 · Сворачивание слитых веток

- [ ] С включённым в Preferences режимом ветка, слитая через merge, свёрнута в строку merge-коммита: там треугольник и число коммитов; клик раскрывает её (граф перестраивается, прокрутка на месте), повторный — сворачивает; раскрытое остаётся раскрытым до переключения репозитория; при «только первых родителях» режим неактивен.
