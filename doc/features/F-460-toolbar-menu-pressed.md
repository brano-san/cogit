# F-460 · Кнопка тулбара с открытым меню остаётся нажатой

Пока открыто меню split-кнопки тулбара (`Pull`, `Rebase`, `Stash`…) или меню `More actions`,
кнопка подсвечена и обведена, как нажатая, — меню видно висящим на ней. Каретка стоит по
середине строчных букв подписи, а не у верха строки, при любом системном шрифте.
Проверить: открыть меню `Rebase` — кнопка нажата, закрыть — отжата; каретка по центру подписи.
