# F-313 · Stash: диалог с тремя режимами и быстрые варианты

Кнопка Stash открывает диалог `Stash All` с полем имени (ошибка «Enter a name.» — под
полем) и кнопками `Stash All`, `+ Keep Index`, `+ Keep Working Tree`; меню кнопки —
`Stash Selection` (со списком файлов и подтверждением), `Quick Stash All`,
`Quick Stash Selection`. Проверить: изменить файл, `Stash` → `+ Keep Working Tree` — stash
появился в Branches, файл остался изменённым; выбрать файл в Files → `Quick Stash
Selection` — застешен только он.
