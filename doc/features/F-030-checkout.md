# F-030 · Переключение ветки

- [ ] Двойной клик по локальной ветке в Branches или `Check Out` в её контекстном меню
      переключают на неё, после чего граф, файлы и HEAD перечитываются. Кнопки при наведении
      у строки нет.
- [ ] Двойной клик — то же, что `Check Out` меню: по `origin/feature` — переключение на локальную
      `feature` (создаётся, если её нет); по тегу — вопрос об отсоединённом HEAD, `Cancel` ничего
      не меняет; по тегу на дереве — ничего.
