# F-030 · Переключение ветки

- [ ] Двойной клик по локальной ветке в Branches переключает на неё, `Check Out` в её
      контекстном меню — после диалога Checkout с описанием ветки, если его не отключили
      (F-555); затем граф, файлы и HEAD перечитываются. Кнопки при наведении у строки нет.
- [ ] Двойной клик по remote-ветке или тегу — то же, что `Check Out` меню: диалог Checkout с
      вариантами (F-555); `Cancel` ничего не меняет; по тегу на дереве — ничего.
