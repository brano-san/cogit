# F-289 · Двойной клик по ворктри делает его активным

Двойной клик по строке Worktrees переключает Graph & History, Files, Branches и Diff на этот
ворктри, как у подмодуля; дерево Repositories не перестраивается, а репозиторий-владелец
помечен иконкой ворктри. Проверить: двойной клик по linked-ворктри — в Branches выделена его
ветка, в Repositories — метка у владельца.
