# F-244 · Окном управляет Windows, а не Cogit

- [ ] Maximize разворачивает окно на том мониторе, где оно сейчас, с первого нажатия и без переездов.
- [ ] Перетаскивание к верхней границе, `Win+↑`, `Win+←/→` работают штатно, окно не дрожит, содержимое занимает всю площадь.
- [ ] Minimize сворачивает окно в панель задач, и клик по значку возвращает его туда же, откуда свернули.
- [ ] Окно, сохранённое развёрнутым, открывается развёрнутым.
- [ ] `Window ▸ Reset Window Position` возвращает окно в центр основного монитора.
