# Один индикатор активности

Спиннер и текст текущей операции показываются только в футере, а тулбар остаётся кнопками.

Длинные имена футер усекает многоточием, а не выталкивает индикатор за край: первыми
сжимаются upstream и сводка, затем имя репозитория и ветка; полный текст — в подсказке.
Проверить: окно 1024 px, ветка на 50 символов с одноимённым upstream — `Pushing… 45%`,
`Error` и кодировка справа видны.
