# F-301 · Отдельные окна не ломают главное

Двойной клик по файлу открывает окно diff с содержимым на всю клиентскую область, без меню,
закрываемое крестиком, `Esc` и `Ctrl+W`. Проверить: десять раз подряд открыть и закрыть окно
diff, между разами выбирать коммиты в графе — главное окно каждый раз обновляет данные.
