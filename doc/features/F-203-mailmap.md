# Авторы сводятся через .mailmap

Граф, детали коммита (автор и коммитер), Blame, Investigate, история строки, лог файла и
поиск по автору показывают имя и почту так, как их показывает `git log --use-mailmap`:
`.mailmap` в корне рабочего дерева (в bare-репозитории — `HEAD:.mailmap`), затем
`mailmap.blob`, затем `mailmap.file`. Поиск по автору ищет по сведённому имени и адресу, как
`git log --author`.

Аватар запрашивается по сведённому адресу: у человека, который коммитил с нескольких адресов,
сведённых в один, — одна картинка.

Правка `.mailmap` подхватывается без перезапуска: граф и детали выбранного коммита
перечитываются сами; Blame и Investigate — при следующем открытии. Сломанный или
отсутствующий `.mailmap` ничего не ломает. Решение и расхождения с gix — R-390.
