# F-353 · Меню коммита в графе

Правый клик по коммиту: Check Out … Copy ID в порядке и с разделителями из #38, `Reset
Advanced…` — диалог пяти режимов с пояснениями. Проверить: у запушенного коммита `Squash`
неактивен с «(already pushed)», а `Edit Message` сначала предупреждает о переписывании
опубликованной истории; `Reset Advanced… → Hard` спрашивает подтверждение, Undo возвращает
ветку на прежний коммит и выброшенные правки на неё (R-432); Undo `Reset` любого режима
возвращает ветку.
