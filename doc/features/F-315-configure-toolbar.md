# F-315 · Настройка тулбара

`Preferences ▸ Toolbar` (`Ctrl+,` или правый клик по тулбару → `Toolbar Preferences…`)
добавляет, убирает и переставляет кнопки тулбара; каждое изменение сразу видно на тулбаре за
диалогом, `Undo` в разделе отменяет изменения этого окна по одному, `Restore Defaults` —
исходный набор, `Cancel` — раскладка, какой была при открытии; раскладка сохраняется между
запусками. Пункта `Edit ▸ Configure Toolbar…` нет (R-371). Проверить: убрать `Discard`,
поднять `Stash` выше `Stage` — тулбар изменился сразу; `Undo` дважды — вернулся;
перезапустить — раскладка та же.
Разделитель, который тулбар всё равно убрал бы (в конце или рядом с другим), не добавляется:
`Add →` для него неактивна, и шага `Undo` без видимого изменения нет.
