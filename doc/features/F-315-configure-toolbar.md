# F-315 · Настройка тулбара

`Edit ▸ Configure Toolbar…` (или правый клик по тулбару) открывает диалог, где кнопки
тулбара добавляются, убираются, переставляются и сбрасываются к умолчанию; раскладка
сохраняется между запусками. Проверить: убрать `Discard`, поднять `Stash` выше `Stage`,
`OK` — тулбар изменился; перезапустить — раскладка та же; `Reset to Default` → `OK` —
исходный тулбар.
