# F-024 · Коммит

- [ ] Поле сообщения под списком файлов коммитит застейдженное по Ctrl+Enter, считает длину темы и подсвечивает превышение 50 и 72 символов.

`Local ▸ Commit…` и `Ctrl+Enter` из любого места окна показывают панель Commit Message, ставят
курсор в поле и коммитят, если коммит готов; `Ctrl+Shift+Enter` — то же с Amend, `Ctrl+K` —
только курсор в поле (R-452).
