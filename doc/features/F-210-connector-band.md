# Соединительная полоса между панелями diff

В side-by-side между колонками идёт полоса, где каждый блок правок соединён лентой на
кривых Безье с тем, что ему отвечает на другой стороне; перемещённый блок соединён
пунктирным контуром, а не заливкой, и его концы находят друг друга, как бы далеко по
файлу ни разъехались.
