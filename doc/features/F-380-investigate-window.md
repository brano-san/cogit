# Окно Investigate

`Investigate` открывает отдельное окно `<файл> [<репозиторий>] - Investigate` со своим меню
(File, Edit, View, Go To, Window, Help), кнопками Back (со списком мест) и Forward,
переключателем перспектив Log / Diff / Blame / Blame+Origins / Origins и панелью
Navigation — лог коммитов файла с графом через переименования; окно закрывается крестиком,
`Esc` и `Ctrl+W` и не трогает главное окно.
