# F-043 · Создание тега

- [ ] Кнопка Tag ставит тег на текущий коммит; непустое сообщение делает его аннотированным.
- [ ] Сразу после `git init` Tag в тулбаре, палитре и меню неактивен («There is no commit to tag
      yet») — без уведомления-ошибки; на orphan-ветке с выбранным в графе коммитом — активен.
