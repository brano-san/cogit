# F-237 · Открытый репозиторий виден во всех панелях сразу

- [ ] Открыть репозиторий: граф, ветки, файлы и diff показывают его без единого нажатия — прятать и возвращать панель по `Ctrl+3` не требуется.
- [ ] Счётчик в заголовке панели и её содержимое всегда об одном и том же: «Graph & History (348)» над пустой панелью невозможно.
- [ ] Пока репозиторий открывается, панели пишут `Opening repository…`, а не `No repository open`.
- [ ] Статус в футере всегда заканчивается: успехом, ошибкой или, если бэкенд молчит, сообщением о слишком долгом открытии.
- [ ] Коммит в терминале рядом с Cogit перечитывает репозиторий, не гася панели.
