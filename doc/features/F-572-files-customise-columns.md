# F-572 · Customise View: колонки таблицы Files

- [ ] Кнопка `Customise View` (иконка таблицы) в Files открывает меню: `Columns` — Name (всегда,
      неактивна), Type, State, Path; снятая галочка убирает колонку и её заголовок, выбор
      переживает перезапуск. В дереве Path неактивна с подсказкой. У рабочей копии ниже —
      `Rename Sources`; в узкой панели — ещё шесть переключателей состояний (R-597).
