# F-240 · Окно всегда открывается там, где его видно

- [ ] Перенести настройки на машину с другим экраном: окно открывается внутри экрана, заголовок можно схватить мышью.
- [ ] Окно, сохранённое на втором мониторе, открывается на нём, пока он подключён, и возвращается на основной, когда его отключили.
- [ ] Окно никогда не больше экрана, на котором открылось.
- [ ] `Window ▸ Reset Window Position` возвращает окно в центр основного монитора.
