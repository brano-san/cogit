# F-441 · Только первые родители

- [ ] С включённым в Preferences режимом «только первые родители» граф — по одной линии на каждую отмеченную ссылку, как `git log --first-parent`: коммиты веток, влитых через merge, не показываются, у merge-коммита нет линии к ним; при выключении граф возвращается целиком.
