# F-251 · Лица в списке коммитов

Аватары включены по умолчанию: колонка фиксированной ширины сразу после имени автора
([F-266](F-266-avatar-after-author.md)), пока картинки нет — инициалы на цвете, посчитанные
локально. Тот же аватар стоит в панели Diff у строки Author. Проверить: открыть репозиторий с
несколькими авторами — колонка не прыгает по мере загрузки картинок.
