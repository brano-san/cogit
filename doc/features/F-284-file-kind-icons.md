# F-284 · Тип записи в Files отдельно от состояния

Слева в строке Files — иконка типа (файл, подмодуль, символическая ссылка, каталог), за ней
отдельно маркер состояния; тип берётся из режима записи, и подмодуль с `M` в рабочем дереве
показан иконкой подмодуля — той же, что в Repositories. Проверить: переключить подмодуль на
другой коммит и посмотреть на его строку в Files.
