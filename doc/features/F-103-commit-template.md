# F-103 · Шаблон сообщения коммита

- [ ] Если в конфиге задан `commit.template`, пустое поле сообщения заполняется этим шаблоном — но уже начатый черновик не перетирается.
- [ ] Строки-подсказки шаблона (начинаются с `#` или `core.commentChar`) в коммит не попадают, как у `git commit` с редактором; свои строки с `#`, например `#123 fix`, остаются. Нетронутый шаблон не коммитится: кнопка неактивна.
