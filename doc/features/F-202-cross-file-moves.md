# Перемещение между файлами отличается от перемещения внутри файла

- [ ] Движок помечает блок, уехавший в другой файл коммита, как перемещение со `moveScope`
  `acrossFiles`, а перемещение внутри одного файла — `withinFile` (`diff_files`, второй проход
  `link_moves_across_files`; тест `diff_engine/tests/moves_across.rs`).
- Во вьюере этого пока нет: панель Diff грузит один файл за раз (`diff_file`), и блок,
  перенесённый в другой файл, выглядит как удаление в одном и вставка в другом. Почему не
  подключено и не удалено — R-447.
