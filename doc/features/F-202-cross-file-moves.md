# Перемещение между файлами отличается от перемещения внутри файла

Блок, уехавший в другой файл коммита, помечается как перемещение со `moveScope`
`acrossFiles`, а не как удаление в одном файле и добавление в другом; перемещение внутри
одного файла остаётся `withinFile`, и вьюер рисует их по-разному.
