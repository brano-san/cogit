# Разделение работ: две ветки, 80 шагов

Дата: 21 сентября 2026. Точка ветвления — `f8adcd3`.

Две ветки идут параллельно. Ветка `diff-merge` живёт в отдельном git worktree, `master`
остаётся за основным агентом. Когда обе закончат, `master` забирает `diff-merge` с ревью.

Всё разделение подчинено одному: **конфликт возникает там, где две ветки правят один
участок одного файла.** Поэтому territory расписана по файлам, а не по задачам.

### Общие файлы и правило для них

В четырёх файлах стоит разделитель. **Ветка `diff-merge` дописывает строго ниже него,
`master` — строго выше.** Git сливает такие правки без конфликта, потому что участки не
соприкасаются.

| Файл | Разделитель |
|---|---|
| `src-tauri/src/lib.rs` | `// ─── diff-merge branch appends below; master inserts above ───` |
| `src-tauri/src/commands/mod.rs` | в конце файла |
| `crates/app_state/src/lib.rs` | в конце файла, отдельный `impl AppState` |
| `frontend/src/lib/ipc/index.ts` | в конце файла |
| `doc/12-risks.md` | HTML-комментарий в конце |
| `doc/features/README.md` | HTML-комментарий в конце |

**`frontend/src/lib/ipc/bindings.ts` не сливается никогда.** Он генерируется. При слиянии
берётся версия `master`, потом выполняется `cargo run -p cogit --bin export-bindings`.
То же правило для любых snapshot-файлов `insta`.

## 2. Порядок запуска

Первые шесть шагов `master` разбирают `App.svelte` (1900 строк) на контейнеры панелей.
Пока они не влиты, ветка `diff-merge` **не трогает фронтенд** — её первые пятнадцать шагов
целиком в Rust. После влития декомпозиции ветка делает `git rebase master` и получает
`components/panels/DiffPanel.svelte` как свою точку входа.

## 6. Протокол слияния

1. Ветка `diff-merge` доводит свои сорок шагов до зелёного: `cargo clippy -D warnings`,
   `cargo test --workspace`, `npm run check`, `npm run test`.
2. `master` доводит свои.
3. Ветка делает `git rebase master` **у себя** и чинит своё же. Конфликтов ждём только в
   `bindings.ts` — он берётся с `master` и перегенерируется.
4. `master` сливает ветку и делает ревью: каждый её коммит читается на предмет нарушения
   границ территории, а не только на корректность.
5. После слияния — `cargo run -p cogit --bin export-bindings`, полный прогон, пересборка
   релиза.
