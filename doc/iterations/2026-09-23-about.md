# Итерация: доработка окна Help ▸ About Cogit

Исходное состояние проверено по ветке от `db0c932`: About собран на общем шаблоне
`Dialog.svelte`, своих отступов у тела нет, ссылка на GitHub — голый `<a>` без класса,
путь к логу — кнопка цвета `--text-link`, строки — одна сетка `dl` из `versionRows`.
Приложение не запускалось (запуски выключены): всё проверено тестами, `svelte-check` и
чтением кода; внешний вид после слияния с правками шаблона надо посмотреть глазами.

### Написание

Интерфейс в основном британский (`Theme & Colours`, `Behaviour`, `Maximise Panel`,
`Initialise this submodule`, `MIT licence`). Исправлено американское:

- `Colored branch lines` → `Coloured branch lines` (настройки);
- `Submodule … is not initialized. Initialize…`, заголовок и кнопка `Initialize` →
  `initialised` / `Initialise` (вопрос при открытии неинициализированного подмодуля);
- `Submodule is not initialized: …` → `initialised` (текст ошибки, фронтенд и `git_engine`);
- `Not checked out yet. Initialize it…` → `Initialise` (подсказка в дереве репозиториев);
- `virtualization` → `virtualisation` (подсказка кнопки переноса строк в выводе команды).

Осталось: `Customize View` в тулбаре Files — файл панели Files вне моей зоны, правка в
одно слово. Идентификаторы (`maximize-panel`, `coloredLanes`) не трогал: это не текст
интерфейса.

## Тесты

- `git_engine::version` — версия `gix` из трёх чисел;
- `app_state::environment` — 13: имя Windows по сборке, редакция, сервер, пустое имя,
  macOS и Linux, рендерер по платформе, реальная ОС этой машины;
- `app_state::settings` — путь к файлу настроек совпадает с записанным;
- `app_state::licences` — 3: документ из двух списков, dev-сборка без фронтендного списка,
  запись файла;
- `build_info::licences` — 9: только линкуемые крейты, без dev/build и своих, алфавит без
  учёта регистра, лицензия из файла или `unknown`, ошибки формы метаданных, вывод;
- `build_info::process` — 3: вывод, ошибка, остановка по таймауту;
- фронтенд: `diagnostics` — 24, `path-truncate` — 9, `third-party` — 11.
