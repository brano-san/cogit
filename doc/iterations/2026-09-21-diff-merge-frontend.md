# Ветка `diff-merge`: второй заход, фронтенд

Продолжение [первого захода](2026-09-21-diff-merge-rust.md). База — `6204200`, после
второго `git rebase master`. Точка входа `components/panels/DiffPanel.svelte` на месте.

**Цель:** пункты 2–6, 15, 16, 19–29, 36 из [§3 split-документа](2026-09-21-split.md).

## Ограничения этого захода

- Территория прежняя. `frontend/src/lib/settings.ts` и `stores/settings.svelte.ts` —
  `master`, поэтому свои настройки ветка хранит своим ключом в том же `settings.json`
  через `@tauri-apps/plugin-store`. Это данные, а не исходник: конфликта файлов нет.
- `components/panels/DiffPanel.svelte` — `master`. Всё новое делается внутри
  `components/diff/**`, чтобы не трогать его пропсы.
- DTO уже готовы первым заходом: `moveId`, `moveScope`, `noNewline`, `diffFiles`,
  `investigate`, `fileBefore`.
