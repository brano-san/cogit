## Открытые вопросы

- [ ] **Релизная сборка падает при запуске с `0xC000001D` — не подтверждено.**
      Свежая сборка выходит сразу после строки `cogit starting` в логе; это `ud2`,
      то есть Rust `abort`. Но предыдущая сборка того же кода запускалась и
      отрисовалась, а разница между ними — удаление одной строки текста из
      `.svelte`. Запуск из песочницы даёт `exit 0` без окна и без дампа, то есть
      ведёт себя не так, как настоящий рабочий стол.

      Статически проверено и исключено: дублей id в меню нет, `unwrap`/`expect` на
      пути старта нет, `.window-state.json` и `settings.json` целы, чистый профиль
      WebView2 не помогает.

      **Как проверить:** двойной клик по `target\release\cogit.exe`. Окно открылось —
      дело в песочнице, вопрос закрыт. Не открылось — в `AppData\Local\CrashDumps`
      лежат два дампа от 21.09 14:54, по ним видно точное место.

## Что стоит сделать следующим, когда проверки пройдены

Ничего из этого не числится невыполненным пунктом — это то, что выросло из работы:

1. **Аватары из GitLab и GitHub.** Контракт `avatars::Source` под них готов. GitLab —
   один GET без авторизации, но адрес уходит открытым текстом; GitHub требует токена и
   десять запросов в час. Оба — отдельное решение о приватности, не просто код.
2. **Markdown в синтаксическом слиянии**, если найдётся честное правило независимости.
3. **Компонент тултипа** сейчас стоит только в тулбаре; остальные места по-прежнему на
   атрибуте `title`. Перевести их — работа на полдня, выгода спорная.
