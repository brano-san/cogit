# Итерация: доработка диалога подтверждения выхода

Каждый пункт сначала проверен по коду ветки `master` на `db0c932` (запуски приложения
выключены), затем правлен. Статусы: **уже было**, **сделал**, **не сделал и почему**.

## 1. Что было до правки

- Диалог Exit — на общем `Dialog`, но у `.body` шаблона не было отступа, а Exit своего не
  клал: иконка у рамки. Чекбокс — нативный `<input>`, в тёмной теме белый квадрат.
- Пояснение «By closing the last window…» показывалось всегда, в том числе после
  `Repository ▸ Exit` и `Alt+X`.
- Вариант с операциями: снимок `list_operations` в момент закрытия, блок «N operations have
  not finished» внутри того же вопроса, те же `Cancel` / `Exit Now`, чекбокс виден, **Enter —
  Exit Now** (шаблон вызывал `onconfirm` при любом фокусе). Список не обновлялся.
- Строка «Exiting stops them» не соответствовала коду: дочерний git на Windows переживал
  Cogit, push продолжался без окна.
- Выключение Windows до Cogit как `CloseRequested` не доходило вовсе: диалог не появлялся,
  идущие операции обрывались системой.
- «Don't show again» и `Confirm before exiting` — одно значение `settings.confirmExit`,
  сохраняется только по `Exit Now` — это работало.
