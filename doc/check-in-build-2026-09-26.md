## Cogit: что проверить глазами (сборка 26.09.2026)

Поведение закрыто тестами; ниже — то, что тесты не видят: вид, фокус, мышь, реальный git.
Сборка — `target/release/bundle` (11f7b25). Отметки 4 темы — Dark, Dark gray, Light,
Light gray. Сначала раздел A — там новое и больше всего шансов на сюрприз.

### A. Правки 25.09 (`doc/cogit-tasks-2026-09-25.md`)

**Окно Diff (двойной клик по файлу)**
- [ ] Строка длиннее окна: полоса прокрутки снизу, Shift+колесо и тачпад листают вбок; каждая колонка Side by side — в своей ширине.
- [ ] Rust- или TS-файл, ханк посреди функции: `fn`, `let`, строки — одного цвета целиком; изменённое слово сохраняет цвет токена.
- [ ] Next/Prev change — изменение, к которому перешли, коротко вспыхивает.
- [ ] Полоса между колонками тянется мышью, ←/→ с фокусом на ней, двойной щелчок — поровну; ширина сохраняется после перезапуска.
- [ ] Шапка справа: «Commit a1b2c3d vs parent d4e5f6a», в подсказке — что слева, что справа.
- [ ] Ctrl+F над текстом и над бинарным файлом — наш поиск, не браузерный (и в главном окне).
- [ ] Имя файла — в заголовке окна и один раз в шапке, не в начале diff.
- [ ] Пустая половина строки (напротив удалённой/добавленной) заштрихована; лента между колонками — красная у удаления, зелёная у вставки; 4 темы.
- [ ] Двойной клик по изменённому submodule — он становится активным, окно не открывается.
- [ ] Файл > 1 МБ и бинарный (`image.bin`, файл с `binary` в `.gitattributes`): сообщение с причиной «invalid character 0x.. in line N, at position M», размеры в байтах, полные id сторон.
- [ ] Удалённый бинарный или картинка — «Not there: the file is deleted», а не «N → 0».

**Repositories**
- [ ] Новый неотслеживаемый файл в неактивном репозитории — оранжевая точка есть и не пропадает при переходе на другой.
- [ ] Правка файла внутри submodule — точка у узла submodule и у проекта; коммит в submodule из терминала — у узла стрелка вверх (если есть upstream).
- [ ] Метки узлов submodules приходят примерно через 1,5 с после открытия или записи (R-617) — это ожидаемо.
- [ ] Стрелки push/pull крупнее; push оранжевая, pull зелёная; 4 темы.
- [ ] Submodule `behind` на ветке с длинным именем в узкой панели — метка `behind` видна, режется ветка.
- [ ] Открыть репозиторий с вложенными submodules — первый уровень раскрыт, вложенные свёрнуты; свёрнутое не раскрывается при переключении.
- [ ] A → кликнуть его submodule → правка или Refresh → Close на A: submodule не появляется отдельной строкой.
- [ ] Правый клик по невыбранной строке — строка обведена, пока открыто меню; выбор не меняется.
- [ ] Заголовки Repositories и Files: оранжевая точка не мигает раз в секунду (особенно `dtv_device`).

**Remote и Branches**
- [ ] Push новой ветки из её меню — в графе одна метка `origin=<ветка>`; в Push To есть флажок Set upstream.
- [ ] Push ветки без upstream: один remote — уходит сразу с upstream; два remote — открывается Push To с выбором.
- [ ] Pull на ветке без upstream — без ошибки, в Output `git fetch --all`; Sync неактивен с причиной.
- [ ] `git remote add upstream <url>` — в Branches появляется узел `upstream (0)`.
- [ ] Правый клик по HEAD, Local Branches, Tags, Stashes, Lost Commits, папке, remote — у каждого своё меню, везде есть Toggle; у Tags — Add Tag, у Local Branches — Add Branch.
- [ ] Меню remote: Rename (узел и отметки переходят), Delete (спрашивает, называет URL), Copy URL, Properties (URL + фоновая проверка), Fetch More на клоне `--single-branch` (повтор — «Nothing new»), Set Depth на клоне `--depth=1`.
- [ ] Set Upstream… и Stop Tracking в меню ветки; Stop Tracking неактивен без upstream.

**Двойной клик и Checkout**
- [ ] Двойной клик: папка — сворачивается; HEAD — ничего; локальная ветка — диалог с `Don't show again`; тег — `Create local branch` или `(just read-only)`; remote-ветка — `Track remote branch` и, если есть отслеживающая локальная, `Checkout and fast-forward local branch '<имя>'`.
- [ ] В графе: двойной клик по коммиту, по метке ветки, по тегу — тот же диалог; двойной клик по кнопке сворачивания диалог не открывает.
- [ ] Stash: двойной клик и пункт меню — Apply Stash (Apply, Apply & Drop, Restore Index).
- [ ] Checkout с изменениями — предложение перенести их; без конфликтов stash исчезает, с конфликтом — остаётся в списке и об этом сообщают.
- [ ] Диалоги Checkout, Apply Stash, Autostash: фокус, Enter, стрелки по радиокнопкам; 4 темы.

**Граф**
- [ ] Отмечен только `master`, HEAD на feature с влитым master — полоса master серая, чужая история не подсвечена.
- [ ] Тянуть сплиттер Diff быстро и медленно при 125 % и 150 % — линии графа не съезжают с текста.
- [ ] Баннер merge — только Abort; у rebase, cherry-pick, revert — Continue остался.
- [ ] Поле `Filter`: при вводе строка переключателей Author, Committer, Message, Refs, ID, Name, Content (Name и Content выключены); Name и Content работают.
- [ ] Кнопка настроек справа: 4 раскраски (Mergeable — новая), First Parent, Only Selected, Include Tracked Remote, Show Graph While Filtering, Show Working Tree Permanently; значения совпадают с Preferences и меняются вместе.
- [ ] «Домой» и «Назад»: с Working Tree, с HEAD, с другого коммита; «Назад» неактивна без истории.
- [ ] Лупа: Remember Pattern, выбор шаблона подставляет его, удаление; с клавиатуры.
- [ ] Строка Working Tree на чистом дереве — по переключателю.

**Bisect**
- [ ] Меню коммита ▸ Bisect ▸ Start…, отметки Good/Bad/Skip из баннера; в конце — первый плохой коммит выбран, диалог Bisect Finished.
- [ ] `git bisect start/bad/good/reset` в терминале — баннер появляется и уходит сам.
- [ ] Точки good/bad/testing и тон строк — в 4 темах, с Varying Coloring.

**Files**
- [ ] Separate Working Tree and Index выключен — один список без заголовков; частично застейдженный файл один раз, бейдж в пунктирной рамке.
- [ ] Включённый переключатель остаётся синим под указателем — в Files, Branches, Investigate, окне слияния; 4 темы.
- [ ] Кнопки в заголовках Unstaged/Staged видны всегда, на строках файлов кнопок нет; узкая панель режет подпись, не кнопки.
- [ ] Дерево/плоский список — одна кнопка, иконка и подсказка меняются.
- [ ] Таблица: Name, Type, State, Path; заголовки ровно над колонками (с полосой прокрутки и без); пути с одной вертикали; щелчок по заголовку — сортировка, повторный — обратная.
- [ ] Customize View — группа Columns; Path в дереве неактивен с причиной.

**Clone**
- [ ] Repository ▸ Clone… и палитра; ссылка GitHub в буфере подставляется, обычный текст — нет.
- [ ] Неверный URL — вывод git и Continue Without Check; приватный репозиторий — окно учётных данных во время клона.
- [ ] Список веток с `(default)`; поле MB неактивно без Skip large files; непустая папка — Finish неактивна с причиной.
- [ ] Прогресс «Cloning…» в футере, Cancel останавливает и убирает папку; после — репозиторий открыт и в списке.

**Общее**
- [ ] Американское написание: Remote ▸ Synchronize, Submodule ▸ Initialize, View ▸ Maximize Panel, Preferences ▸ Theme & Colors, Behavior, темы Light gray/Dark gray, About ▸ Third-party licenses, Customize View.
- [ ] Футер: треугольник и число ошибок по центру; во время fetch рядом Cancel той же высоты; 100/125/150 %.
- [ ] Edit Git Config на репозитории с конфигом 60+ строк — путь виден целиком, в узком окне режется середина.
- [ ] Чередование строк в Files, Repositories, Branches, Worktrees — не переезжает при прокрутке; выделенная, наведённая и строка под меню сплошные; выключается тем же «Alternate row background».
